### 3.2 单调同序与秩相关（逐维）

- 逆序对定义：对每一对 (i,j)，若 `(main_i − main_j) × (aux_i − aux_j) < 0` 记 1，最后除以 2；并列（乘积 = 0）不计。
- 结果：**50/50 维逆序对均为 0，总数 0**——仿射严格递增 + ALR 非降，两表不可能出现反向序对。
- Spearman(辅助表, 主表)：**min 0.416757（stale_hops）、max 0.998154**；50/50 维 <0.999。
- 对照（不作为判据，只解释成因）：主表逐维等级数 2–5（2 级 3 维、3 级 16 维、4 级 21 维、5 级 10 维），辅助表逐维等级数 5–7（5 级 2 维、6 级 13 维、7 级 35 维）；两表仅 **55.9%** 格子等级相同。

### 3.3 Spearman 未达 0.999 的机理与裁定

- 指定公式为**全方差对齐**：`SD_label / SD_pred ≈ 2.27`（逐维 2.1–2.6），即把 OOF 预测的刻度拉宽到标签尺度；再套同一锚点，必然把原本挤在中间 2–5 级的样本铺到 5–7 级。
- 因此辅助表与主表是对**同一 OOF 排序的不同量化**：主表弱维只用 2–3 级（如 stale_hops 3 级、A_malt_bread 2 级），在这些维上与一个 5–7 级量化求秩相关，理论上的可达上界远低于 0.999。
- **硬门 2 的 Spearman≥0.999 与硬门 3 的"全表 7 级都出现"在指定公式下互斥**（无解）。人类 2026-10-24 裁定：按公式交付、如实报告 min 0.416757；单调同序由逆序对 = 0 精确证明；不改公式、不改锚点、不拉伸。
- 备查（若审阅官改判据）：`Spearman(x′, x) = 1.0`（仿射严格单调）、"并列用同一 OOF 连续值破并列后的秩相关 = 1.0"；两者均为恒等性质，不增加信息。

## 4 参数可复算（第二人视角）

只读 `Q1_可读口径参数.json` + `Q1_感官连续_OOF.csv`，不调用生产脚本：

```python
import json, numpy as np, pandas as pd
j = json.load(open("编程/产出/Q1_可读口径参数.json", encoding="utf-8"))
oof = pd.read_csv("编程/产出/Q1_感官连续_OOF.csv", encoding="utf-8-sig")
aux = pd.read_csv("编程/产出/Q1_感官评分_可读口径.csv", encoding="utf-8-sig", comment="#")
dims = [d["dim"] for d in j["dims"]]
g = np.zeros((250, 50), dtype=int)
for k, d in enumerate(j["dims"]):
    xp = d["mu_label"] + (oof[d["dim"]].to_numpy(float) - d["mu_pred"]) * d["scale"]
    s = np.round(6.0 * (xp - d["anchor_lo"]) / (d["anchor_hi"] - d["anchor_lo"]), 10)
    g[:, k] = np.clip(np.floor(s + 0.5), 0, 6).astype(int)
print("equal", int((g == aux[dims].to_numpy(int)).sum()), "/ 12500")
print("freq", np.bincount(g.reshape(-1), minlength=7).tolist())
```

实测输出：

```text

freq [2945, 3221, 2634, 2020, 1183, 412, 85]
```
