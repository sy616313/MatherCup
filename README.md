# 数学建模竞赛协作仓库

> 面向多人 + 多 AI 的数学建模竞赛协作仓库。所有结论落盘，所有路径以仓库根目录为基准。

## 快速开始

1. 打开 `START-HERE.md`，按里面的顺序读。
2. 读 `AGENTS.md`；如果你的工具不会自动加载，手动打开。
3. 找到自己的角色卡和当前任务书。
4. 技能在 `资料/技能/<名称>/SKILL.md`，直接读全文，不依赖工具自动加载。

## 角色与写区

| 角色 | 主要写区 | 不做什么 |
|---|---|---|
| 大脑 | `状态板.md`、`台账.md`、`审阅/规划/`、各角色 `任务书/` | 不做实质推理、不写结论 |
| 建模 | `建模/产出/`、`建模/快照/` | 不写生产代码、不填结果文件 |
| 编程 | `编程/产出/`、`编程/快照/`、`图集/Mx/` | 不改模型设定 |
| 论文 | `论文/产出/`、`论文/快照/` | 不自行计算数值 |
| 审阅官 | `审阅/Mx/` 的裁决与核验报告 | 不改交付物、不代做返工 |
| 第三方校验 | 无（结论由大脑转录） | 不执行任务、不改方案 |

## 文档入口

- `AGENTS.md`：总章程
- `START-HERE.md`：冷启动指引
- `状态板.md`：当前进度
- `台账.md`：裁决史
- `规范/Git协作规范.md`：分支、PR、tag
- `资料/技能/README.md`：17 个技能怎么用
- `模板/`：任务书、快照、审阅报告、裁决

## Git 约定（摘要）

- `main` 受保护，不直接 push。
- 一个任务一个分支：`task/T1-001-角色`。
- 一个任务一个 PR，合并后打里程碑 tag。
- 详细规则见 `规范/Git协作规范.md`。

## 注意

- 不要提交 `.venv/`、`__pycache__/`、LaTeX 中间件、`.npz` 中间结果。
- 不要使用盘符绝对路径、用户主目录绝对路径或本地文件协议链接。
- 外部原文库不随仓库分发；如团队有副本，放到 `资料/原始资料/外部资料/`，可选。
