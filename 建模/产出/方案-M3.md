### 1.3 三个模型（超参全部写死；Ridge 仅作对照、不参与选型）

三个模型按正式任务书 §②-1.1 定：Ridge（对照）、RandomForest、HistGradientBoosting。均为逐维独立训练（50 个回归器，顺序按 §1.1 维度清单）。

| 代号 | 模型 | 超参（完整） | 随机性 |
|---|---|---|---|
| M1 | 岭回归 Ridge（**仅对照，不参与选型**） | `alpha=10.0, fit_intercept=True, solver='auto', tol=1e-4, max_iter=None` | 无随机性（闭式解） |
| M2 | 随机森林 RandomForestRegressor | `n_estimators=500, criterion='squared_error', max_depth=8, min_samples_split=2, min_samples_leaf=3, max_features=0.33, bootstrap=True, oob_score=False, n_jobs=-1` | `random_state=2026` |
| M3 | 直方图梯度提升 HistGradientBoostingRegressor | `loss='squared_error', learning_rate=0.05, max_iter=300, max_leaf_nodes=15, max_depth=None, min_samples_leaf=5, l2_regularization=1.0, early_stopping=False, n_iter_no_change=10, validation_fraction=0.1` | `random_state=2026` |

- 包装方式：`MultiOutputRegressor(estimator, n_jobs=1)`；**逐维独立**，不共享参数、不做多任务学习。
- 全局种子：`random.seed(2026)`、`numpy.random.seed(2026)`、环境变量 `PYTHONHASHSEED=0`；三个模型与折划分共用 2026。
- **一律不早停**（M3 显式 `early_stopping=False`；M2 无早停；M1 无迭代）；**不做网格/贝叶斯调参**；超参是事先给定，不是搜出来的。
- 版本基线（TM3-01 照此 pin，开工前用 §8.2 打印回填）：Python 3.11.15、numpy 2.4.6、pandas 3.0.5、scipy 1.15.0、scikit-learn 1.6.1。本文探针脚本只依赖 pandas/numpy/openpyxl，不依赖 sklearn；**本方案不引入 xgboost**。

### 1.4 交叉验证（折划分方式写死）

```python
import numpy as np
from sklearn.model_selection import KFold

N = 250
kf = KFold(n_splits=5, shuffle=True, random_state=2026)
folds = list(kf.split(np.arange(N)))   # 5 折，每折 50 个样本，固定不变
```

- 一级划分为 **5 折、单次重复**；所有模型、所有特征集、所有维度共用**同一组折索引**；折索引落盘（Q1_折索引.csv，含 beer 与 fold 两列），保证可复算。
- 不分层：`tasting_category_fine` 有 22 类、最小类 3 条，5 折分层会有类不足；折内风格分布作为诊断量报告，不参与任何决策。
- 指标：每维 R²（`1 - SSE/SST`，SST 用该折测试集均值）、MAE；聚合为 50 维算术平均。OOF 预测 = 5 折测试段拼接，覆盖 250 行。

### 1.5 两阶段预注册（伪代码级，跑之前落盘）

**阶段一 · 固定 F1，比三模型定主模型**

```text
X = F1 的 230 列；Y = 4.csv 的 50 维
for model in [M1_Ridge, M2_RF, M3_HGB]:
    for fold in folds(5, seed=2026):
        在训练折 fit，在测试折 predict
    R2_mean[model] = mean_over_50_dims(R2)
主模型 = argmax(R2_mean[m] for m in {M2, M3})      # Ridge 不参与选型
若 |R2_mean[M2] - R2_mean[M3]| < 1e-6：主模型 = M2   # 并列取更简单者
```

**阶段二 · 主模型跑 F0/F1/F2，定特征集**

```text
for fs in [F0, F1, F2]:
    R2_fs[fs] = 主模型在同一 folds 上的 50 维平均 CV R²
按 T0 §六 自上而下三步判定（阈值 0.02）：
  若 R2_fs[F1]-R2_fs[F0] >= 0.02 且 R2_fs[F2]-R2_fs[F1] >= 0.02 -> F2
  否则若 R2_fs[F1]-R2_fs[F0] >= 0.02 -> F1
  否则 -> F0
```

- 两阶段的判定只看 `mean CV R²` **单一指标**，不看逐维、不看 E1/E2/E3、不看测试集。
- **禁止逐维挑模型**：交付只允许"单一主模型 × 单一特征集"；逐维最优只能作乐观上界参考，并标注"不可用于交付，存在选择偏差"。
- 该规则在本文件提交时冻结；TM3-01 只执行、不得改阈值或换指标。

**5.1.3 N_ns 剔除规则（单元级 + 行级）**

- 单元 `(i,d)` 记 N_ns，当且仅当：① 化合物 i 未映射；② 共同非缺失样本数 `n_id < 30`；③ `|r_ref_id| < r_crit(n_id)`，`r_crit(n) = 1.959964 / sqrt(n-1)`（双侧 α=0.05 正态近似；n=250 时 0.1242）；④ 重算 `r_hat_id` 为 NaN（某侧零方差）。
- 行级：某化合物 N_ns 单元占比 >30% → 整行剔除并登记。
- 报告必须含：N_ns 格数/占比、被剔除化合物清单；**不得只报一个平均相关**。

**5.1.4 指标与判据（本方案预注册）**

- 逐格比较 `r_hat_id`（OOF 预测 vs 1.csv 实测）与 `r_id`（6.csv），只在 N_ns 外的格子上统计：
  - 平均绝对差 `mean_abs = mean(|r_hat - r|)`；
  - 方向一致率 `D1 = #{sign(r_hat)=sign(r)} / 有效格数`。
- 判据：`D1 ≥ 0.60` 记"结构一致"；`0.50 ≤ D1 < 0.60` 提示级、不阻断；`D1 < 0.50` 停机上报。`mean_abs` 只报值并作趋势说明，**不设硬线**（6.csv 是外部矩阵，量级受样本与缺失影响）。

- 对每个映射对 k（维度 d_k ↔ 属性 a_k），用 OOF 连续预测与 4.csv 连续标签各算一个相关：
  - `rho_pred_k = rho(预测维_dk, 属性_ak)`；
  - `rho_lab_k = rho(4.csv 该维连续标签, 属性_ak)`。
  - **参照系唯一取 `rho_lab_k`**：观测到的"标签–属性"关联；**不得**改用人工先验方向（那会多一处可争议的自由度）。
- N_ns：`|rho_lab_k| < 0.05` 时参照近零、符号无意义 → 记"不可判"，计入 N_ns 并从分母剔除。
- `N_eff = N_map - N_ns`；判据：
  - `N_eff < 20` → 本条**降级为"仅描述、不作判定"**，只报 N_map/N_ns/N_eff 与原因；
  - `N_eff ≥ 20` → 方向一致率 `R3 = #{sign(rho_pred_k)=sign(rho_lab_k)} / N_eff`；
  - `R3 ≥ 0.60` 通过；`0.50 ≤ R3 < 0.60` 提示级、不阻断；`R3 < 0.50` 停机上报。
- 落盘：Q1_E3映射.csv（attr, dim, 依据列）、Q1_E3逐对.csv（k, dim, attr, rho_pred, rho_lab, sign 是否一致, 是否 N_ns），供审阅逐行复核。
- **不得声称 0–6 真值准确率**：E3 是方向一致性证据，不是分级正确率；报告与论文都要显式声明 P2。

### 5.4 三条证据汇总

| 检验 | 输入 | 有效样本 | 核心指标 | 判据 | 未达标处置 |
|---|---|---|---|---|---|
| E1 | OOF vs 1.csv，对照 6.csv | 42 化合物 × 50 维（N_ns 另计） | 方向一致率 D1、平均绝对差 | D1≥0.60 通过；0.50–0.60 提示；<0.50 停机 | 如实报告 + 上报 |
| E2 | OOF 50 列相关阵 vs 5.csv | 1225 个非对角对 | 平均绝对差、方向一致率 | ≤0.20 一致；>0.20 提示 | 如实报告 |
| E3 | OOF/4.csv 与 7.csv 属性 | N_map=39，N_eff 待算 | R3 方向一致率 | N_eff<20 降级；R3≥0.60 通过；<0.50 停机 | 降级或停机上报 |
