8. 建 231/231 名称对齐：自动 134、人工 97，双射无重无漏。

## 3 关键决策与依据

| 决策 | 依据 |
|---|---|
| 底数 = **10** | 70/70 列 log10 更优；37 列 MAE<1e-6；`ln` 无一列更优 |
| 33 列按**原始量纲**用、不反变换 | 换 `x=y` 假设后 MAE 降到 ≤0.2285 且零负值；按 log10 反解会得出 `10^7256` 级浓度，物理不可能 |
| 名称对齐走 **R→chemical_name 桥接** | 8.xlsx 两张表提供桥；231 双射校验无重无漏 |
| `barnyard` 取 `AG90`、不修源表 | `数据/A/` 只读；`4.csv` 中 barnyard 与 stale_hops 是独立两列 |
| 阈值分三档（原生 / 外部文献 / 缺口） | 方案甲（人类 2026-10-24）：t2n 0.11 µg/L、MeSH 1 µg/L 补外部值；`Stale hops` 维持缺口 |
| Q1 只写 1 种规则（ALR） | R15 减范围；锚点取 P0.5/P99.5 抗离群，`.5` 一律 half-up |
