## 3 关键决策与依据

1. **公式与参数**：严格按任务书写死的仿射式；`μ/SD` 两端各取 250 个值，ddof=0。缩放系数 `SD_label/SD_pred` 逐维在 2.1–2.6 量级，主体由 D 列（预测方差≈0.2×标签方差）决定。
2. **同一锚点**：`q1_anchors.csv` sha256 校验 + M1 §6 表逐行交叉校验；B1/B2/B3 行为与主表实现一致（本表输入无缺失，B2 未触发）。
3. **单调同序的判据**：逆序对 = 0 是精确判据（仿射严格递增 + ALR 非降 ⇒ 两表不会出现反向序对）。
4. **Spearman 如实报告**：逐维 Spearman(辅助表, 主表) min **0.416757**、max 0.998154（50/50 < 0.999）。原因：两表是对同一 OOF 排序的不同量化——主表弱维只用 2–3 级（如 stale_hops 3 级、A_malt_bread 2 级），而辅助表把等级铺到 5–7 级；**在"全表 7 级都出现"的前提下，与主表的 Spearman 不可能≥0.999**。人类 2026-10-24 裁定：按公式交付、如实报告该值，不改公式、不改锚点、不拉伸。
5. **不设逐维等级阈值**：按任务书 ④-4 与 R28，只做表级 7 级检查；逐维频数在 JSON 中如实给出（等级数 5–7，2 维为 5 级）。
