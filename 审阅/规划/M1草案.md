## §0 题目摘要

- **赛题**：2026 MathorCup 数学应用挑战赛——大数据竞赛，**赛道 A：啤酒酿造化合物分析与啤酒风味预测**（题面全文 `数据/赛道A初赛-题面.pdf`）。
- **题型判定**：**大数据/机器学习类**（`shumo-problem-reading` §1 分类树第 ⑤ 类）。判据：三问输入均为附件表格，约束来自题面口径而非物理定律，无需求解器优化目标；无优化类、无机理类成分。
  - Q1 = 多输出回归 + 有序离散化；Q2 = 相关网络 + 特征重要性 + 稳定性选择；Q3 = 条件生成模型。
- **小问清单**：
  - 问题 1：以 `1.csv` 化合物数据为基础，给出 `3.xlsx` 定义的 Aroma 与 Flavour 两套感官维度的 **0–6 分制**分级评分（数据缺失条件）。
  - 问题 2：用 `2.csv` 构建化合物共表达图，结合 `1.csv` 特征，给出每个感官维度的 **Top-3 关键因素化合物**，并做稳定性与化学合理性论证（题面：稳定性可用 bootstrap 入选频率**或**跨方法 Jaccard，为"或"关系）。
  - 问题 3：以 `tasting_category_fine` 为风格标签学条件生成模型，生成指定风格的化合物谱并给出感官画像；做跨风格迁移，且缺陷化合物不恶化（以 DMS/Diacetyl/4VG/trans-2-nonenal/Stale hops 等**超阈值项**为准）。
- **附件数据**（实测）：

  | 文件 | 形状 | 用途 |
  |---|---|---|
  | `1.csv` | 250 × 234 | 化学丰度。234 列 = 3 标识列 + 231 特征；231 = 226 单化合物 + 4 个 `*_sum`（`esters_sum`/`aroma_hops_sum`/`acids_sum`/`sulfur_sum`）+ 1 个 `kcalperc`。缺失 0.12% |

  | `5.csv` | 50 × 51 | 感官相关矩阵；其列名可作 A/B 组可读名，但 C 组列序与 `4.csv` 不同 |
  | `6.csv` | 44 × 51 | 化学×感官交叉相关，非方阵 |
  | `7.csv` | 250 × 189 | 186 个细粒度感官属性（62 属性 × 3 视角 aroma/palate/taste），缺失 1.59% |
  | `8.xlsx` | 7 sheet | 感官阈值 / 感官名称映射 / GBM 全局重要度(232×2) / SHAP / 校准化学浓度(250×73) / 啤酒价格 |
