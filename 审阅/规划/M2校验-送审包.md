## §0 题目摘要（仅 Q2 相关）

- **赛题**：2026 MathorCup 大数据竞赛 · **赛道 A**（啤酒化合物与风味预测）。
- **Q2 原文要求**（`数据/赛道A初赛-题面.pdf`）：利用 `2.csv` 的化合物相关数据构建化合物**共表达图**，结合 `1.csv` 特征，给出每个感官维度的 **Top-3 关键因素化合物**，并进行**稳定性**与**化学合理性**论证。
  - 稳定性题面明确为"**或**"关系：bootstrap 重采样下 Top-3 入选频率 **或** 不同建模方法间 Top-3 的 Jaccard 系数。
- **题型判定**：大数据/机器学习类中的「相关网络 + 特征重要性 + 稳定性选择」。无优化目标、无机理方程。
- **相关附件**（M1 已核定的口径）：

  | 文件 | 形状 | 本方案用途 |
  |---|---|---|
  | `2.csv` | 231 节点 × 231 矩阵（+1 行名列） | 共表达图的**边权来源**；已实测为 **Spearman** |
  | `1.csv` | 250 × 234 | 化合物丰度，用于与 `4.csv` 算每个感官维度的关联强度 |
  | `4.csv` | 250 × 53 | 50 个感官维度（Q2 的排序目标） |
  | `8.xlsx/Sensory thresholds` | 262 原始行 | 化合物→品类的 `origin_paper` 列（化学合理性） |
  | `8.xlsx/GBM importance MDI` | 232 原始行 → **231 化合物 × 2 列** | 全局重要性基线（仅全局，无逐维） |

- **M1 固化的三个前提**（本方案直接引用，不再重算）：
  1. **底数 = log10**（37 列精确成立、70/70 优于 ln）；**另有 33 列本来就没取对数**（原始量纲，无负值）。
  2. **化合物名称对齐 231/231**（`建模/产出/化合物名称对齐-M1.csv`，列：`1csv字段` / `2csv节点名` / `匹配方式` / `备注`）。
  3. **Q2 主 Top-3 候选池 = 226 个节点**（剔除 4 个 `Total*` 与 `Caloric value`，口径 β，R15）。

### §0-1 一个必须先说清的技术前提：变换不影响 Q2

`1.csv` 里**混合了两种量纲**（37 列 log10、33 列原始）。这对 Q2 **不构成障碍**，因为：

> **Spearman 秩相关对任一变量的单调变换不变。** 无论某列是 log10 还是原始量纲，其与另一列的 Spearman 完全相同。

因此 Q2 全程使用 **Spearman**，既与 `2.csv` 的口径一致（C1 已冻结为 Spearman），也天然免疫量纲混合问题。**本方案禁止在 Q2 中使用 Pearson 或任何依赖绝对数值的度量**（如欧氏距离、PCA）。此条写入验收。

## §3 验收标准（每条可回答"是/否"）

1. **`Q2_top3.csv` 结构**：行数 = **50**（与 `4.csv` 的 50 维一一对应，列名用 `4.csv` 代码）；必需列 `dim, rank1, rank2, rank3, score1..3`；每行 `rank1..3` 三个化合物名**均非空且互不相同**；全表无 NA。
2. **候选池合规**：`rank1..3` 出现的所有化合物必须属于 `审阅/规划/T0-Q2候选池.csv` 的 **226** 个节点；**不得出现** `Total ester compounds`、`Total hop aroma compounds`、`Total acids`、`Total sulfur compounds`、`Caloric value`。脚本内以集合断言实现，断言失败即退出码非 0。
3. **稳定性满足题面"或"**：二选一，并在报告中写明选择理由——
   - **甲** bootstrap：`B = 200`（R15），重采样单元 = **样本**（250 个 beer），固定种子；输出 `boot_freq1..3`（该化合物进入该维 Top-3 的频率）。
   - **乙** 跨方法 Jaccard：≥2 种独立排序方法（如 |Spearman| 排序、GBM/随机森林重要度排序），输出两两 `jaccard1..3`。
   - 若两者都做，须同时报，且不得互相替代。
4. **共表达图可核查**：`Q2_参数.json` 记录边阈值规则、节点数、边数；报告中给出 **节点数 = 226**、边数、平均度、连通分量数。若边阈值为 0（全连接），须说明为何仍具"共表达图"意义。
5. **化学品类一致性**：用 `8.xlsx/Sensory thresholds` 的 `origin_paper` 列（取值 Hops / Yeast / Spices / Malt / Others / Wild flora / Internal standard）作为品类标签，经 M1 的 231/231 对齐表桥接到 `1.csv` 字段；报告"Top-3 化合物所属品类分布"与"与所属感官维度预期的品类一致性比例"。
   - 未能归类的化合物**单列清单 + 原因**（如 `origin_paper` 为 `Internal standard`），**不得默认归入 Others**。
6. **GBM 全局对照**：把 50 维 × Top-3 合并为化合物集合（去重），与 `GBM importance MDI`（**231 化合物 × 2 列**，注意该 sheet 首行为占位表头，`header=None` 读 232 行、`header=0` 读 231 行）取交集，报告**重合化合物数与占比**。**不得**声称逐维对照——该表无逐维信息。
7. **聚合列单列说明**：单独一节报告 4 个 `*_sum` 与 `Caloric value` 对 50 维的 Spearman 相关性，并声明其不进入 Top-3 评选；若某聚合列与某维的相关性**高于该维实际 Top-1**，须在正文说明该现象及成因（共线性），不得沉默。
8. **确定性**：固定全部随机源（bootstrap 种子、RF 种子），在仓库根目录重跑 `Q2_共表达.py`，`Q2_top3.csv` 的 md5 **两次一致**；`Q2_参数.json` 内所有影响结果的参数均落盘。
9. **格式门 8 项**（`模板/任务书模板.md` §⑧）：六件套齐全、无 BOM、纯 LF、`python 工具/check_paths.py` 0 错误且输出粘进自检、脚本可移植（环境变量 + 仓库相对默认值）、无未决措辞、CSV 规范、CI 绿。
