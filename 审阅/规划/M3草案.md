## §0 题目摘要（仅 Q1 相关）

- **原题**：*问题 1：数据缺失条件下的感官评分——以 1.csv 化合物数据为基础，给出 3.xlsx 中定义的 Aroma 与 Flavour 两套、共约 40 个感官维度的 0–6 分制的分级评分结果。*（原文：`数据/赛道A初赛-题面.pdf`）
- **题型判定**：**监督回归 + 分档标定**（不是纯预测题）。判据：有 250 条连续标签可监督；题面要求的是"分级评分结果"（离散 0–6），故还有一层"连续→整数"的标定，而这一层**没有真值可学**。
- **输入/输出**：输入 `数据/A/1.csv`（250 行 × 234 列，其中 231 个建模特征 + 3 个标识列）；输出 **250 行 × 51 列**（`beer` + 50 个 0–6 整数列），50 个列名与列序 = `数据/A/4.csv`（53 列 = 3 标识列 + 50 感官列）剔除标识列后的那 50 列。`beer_id` 与 `tasting_category_fine` **不进交付表**：前者 13 位 EAN 被读成浮点、禁用关联（C7），后者是 Q3 的风格标签、不属 Q1 输出。

### §0-1 三条必须先说清的前提（不说清，整问会被判"自说自话"）

| # | 事实（实测，可复现） | 对方案的硬约束 |
|---|---|---|
| P1 | **`4.csv` 不是 0–6 原始分**，是标准化/中心化的连续值（题面原文明写；实测范围 −2.15~6.17，每列 106~250 个唯一值） | 不能把 `4.csv` 当分级标签直接分类；只能先回归连续值、再用自定规则标定 |
| P2 | **`3.xlsx` 的评分卡是空白表单**：0–6 是预印列头，`summary` 612 格全 0（C3） | **0–6 无真值**，标定规则必须自建、自证、显式声明局限；禁止声称"真值准确率" |
| P3 | 题面"约 40 个感官维度"，实测 `4.csv` 为 **50 维**（C5）；人类已裁定按 50 维全量（R13） | 交付 50 维，并在论文中说明"40"的取法差异 |

> **本方案对 P2 的立场**：不假装有真值。标定规则的合法性由 **三类可检验证据**支撑——① 规则本身的单调/保序/边界确定性（T1–T5，见 §3-6）；② 标定前后的信息损失有限（分级值与连续预测的 Spearman）；③ 分级结果对锚点口径的敏感性可量化（§3-6 的敏感性一项）。论文中须有一节写"我们无法验证 0–6 的绝对正确性，能验证的是以下三条"。

## §3 验收标准（每条可回答"是/否"）

### §3-1 结果表结构与预测口径
1. **Q1_感官评分.csv 结构**：行数 = **250**、列数 = **51**（1 列 `beer` + 50 个感官列）；50 个列名与列序与 `数据/A/4.csv` 剔除 `beer`/`beer_id`/`tasting_category_fine` 后**逐字一致**；行顺序与 `1.csv` 的 `beer` 一致；**全部取值 ∈ {0,1,2,3,4,5,6} 的整数**、无 NA。脚本内以 `shape == (250, 51)` 断言，不符即非零退出。
**预测口径（第 1 轮校验问题 2 的裁定，定义性条款，不单独编号）**：三张表口径分离且**不得混用**——
   - `Q1_感官评分.csv`（主交付）＝ **OOF 折外**连续预测经 ALR 标定的结果。理由：它对应"给未见过的啤酒打分"，与论文报告的 CV R² 同口径；
   - `Q1_感官连续_OOF.csv` ＝ 上述 OOF 连续矩阵本身，E1/E2 与全部指标都基于它；
   - `Q1_感官连续_全量.csv` ＝ 全量重训模型的**样本内**预测，**只**供 §3-8 第 18 条自测，不得进入任何指标、图或论文数值。
   三张表的差别须在报告 §1 用一张 3 行小表写明（表名 / 口径 / 允许用途），并在各文件首行注释注明口径。

### §3-2 特征集决策（F0/F1/F2）
2. **三套特征集齐全且列子集正确**：F0 = 226 纯单化合物、F1 = 230（+4 个 `*_sum`）、F2 = 231（+`kcalperc`）；三套的列名清单写入 Q1_特征集定义.json，且与 `1.csv` 列名逐字可核。
3. **决策表按 T0 口径执行**：严格按 `审阅/规划/T0-口径映射与阈值缺口.md` §六 的**自上而下三步**判定（阈值 **0.02**，指标 = 50 维平均 CV R²），命中步骤与理由落盘；判据必须在跑实验**之前**写入 建模/产出/方案-M3.md（G-Q1 门内冻结，提交拓扑可查）。
4. **三套结果全报**：F0/F1/F2 的逐维 R² 与平均值全部入表，不得只报选中的那套。

### §3-3 模型选型（预注册，禁止事后挑）
5. **两阶段预注册**：
   - 阶段一：固定 **F1**，比三种模型（Ridge 仅作对照不参与选型、RandomForest、HistGradientBoosting），主模型 = **50 维平均 CV R² 最高者**，单一指标，不看逐维；
   - 阶段二：用主模型跑 F0/F1/F2，按 §3-3 决策表定特征集。
   两阶段的规则与固定超参（含随机种子）必须在 **建模/产出/方案-M3.md** 中先写死，**跑之前**落盘。
6. **禁止逐维挑模型**：交付表只允许"单一主模型 × 单一特征集"。可另附"逐维最优"作**乐观上界**参考，但必须标注"该列不可用于交付，存在选择偏差"。

### §3-4 标定（0–6）
7. **严格实现 M1 的 ALR 规则**：`score = clip(floor(6·(x−lo)/(hi−lo) + 0.5), 0, 6)`；锚点取 `建模/产出/Q1标定规则-M1.md` §6 的 50 行，**不得重估、不得改口径**；三类边界 B1（超界截断并计数）、B2（缺失用中位数分级回填并置 `imputed=1`）、B3（.5 一律 half-up，判 .5 前先 `round(s,10)`）逐条实现。Q1_标定参数.json 存 50 维的 lo/hi/median/median_score 与 `n_low`/`n_high`。

### §3-5 缺失与鲁棒性（题面标题即"数据缺失条件"）
8. **插补按口径规范**：`1.csv` 的 **73 个缺失格 / 9 列 / 0.126%** 按 `建模/产出/口径规范-M1.md` §7 处理——连续列中位数、**按风格分组取中位数优先**；保留 `*_imputed` 标记列供复核；报告 73 格的插补清单与命中数。
9. **缺失鲁棒性实验**：在测试折上随机 mask 5% / 10% / 20% 的化合物值，各跑一遍，报 50 维平均 R² 与"分级一致率（相对全量结果）"的下降曲线；**不得只报全量结果**。

### §3-6 标定有效性（无真值，只能给间接证据）
10. **T1–T5 全跑并贴输出**：
    - T1 单调性：`[lo−3σ, hi+3σ]` 取 1000 等距点，输出非降、仅 0–6、各级平台存在；
    - T2 保序：把 `4.csv` 的**连续标签** $z_d$ 过规则得参考分级 $s^{ref}_d$，算 $\rho(z_d,\,s^{ref}_d)$ 并逐维报告，判 **ρ ≥ 0.99**。**该检验的对象是规则的单调保序性，不是预测正确性**（0–6 无真值，见 P2）；若某维 $\rho<0.99$，按 §5-1 对应行处置，**禁止**现场改阈值、禁止重估锚点；
    - T3 分布：参考分级 7 类频数表齐全，某级 <2% 须说明；
    - T4 边界确定性：六类输入输出为 `0, 0, 6, 6, 中位数分级, 3`，两次运行一致；
    - T5 往返：100% 复原。
11. **锚点敏感性（新增）**：把 `lo/hi` 换成 `min/max` 与 `P1/P99` 各跑一遍分级，报与主口径的**分级同分率**；只报告，**不改主口径**。
12. **信息损失**：分级值与连续预测的 Spearman ≥ 0.95（每维报，报最小值）。

### §3-7 独立证据（三条，全部要做）
13. **E1 与 `数据/A/6.csv`（46 化学 × 50 感官交叉相关阵）对照**：用我们的连续预测矩阵重算与 `1.csv` 可映射的 46 个指标的 Spearman，与 6.csv 逐格比，报**平均绝对差**与**方向一致率**。
14. **E2 与 `数据/A/5.csv`（50 × 50 感官相关阵）对照**：预测矩阵的列间 Spearman 与 5.csv 逐格比，报平均绝对差。
15. **E3 与 `数据/A/7.csv`（187 感官属性）对照（第 1 轮校验问题 4 的补判据）**：
    - 可映射属性数记为 $N_{m}$；**若 $N_{m} < 20$，本条降级为"仅描述、不作判定"**，写明可映射数与不可映射原因，不触发任何通过/停机结论；
    - **若 $N_{m} ≥ 20$**：对每个可映射对算 $\rho(\text{预测维},\ 7.csv\text{属性})$，定义 **方向一致率 $R_3$ = 符号一致对数 / $N_m$**，判 **$R_3 ≥ 0.60$ 通过**；$0.50 ≤ R_3 < 0.60$ 记为提示级、不阻断；**$R_3 < 0.50$ 停机上报**。
    - 映射表（7.csv 属性 ↔ 50 维）须落盘为 CSV，逐行给依据，供审阅官复核。
16. **不得声称真值准确率**：全文（报告与论文）不得出现"0–6 准确率/命中率"一类表述；必须显式声明 P2。
