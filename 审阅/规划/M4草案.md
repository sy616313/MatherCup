## §3 验收标准（22 条，逐条可判"是/否"）

### §3-1 编译与结构
1. **编译序列完整**：在 `论文/产出` 下依次执行 `xelatex -interaction=nonstopmode main.tex` → `bibtex main` → `xelatex`×2，**四步全部 exit 0**；`main.blg` 中 `error` 0 条；`main.log` 中 `! ` 开头的错误 0 条、`undefined` 引用 0 条、`Citation ... undefined` 0 条。
2. **中文渲染正常**：`main.log` 中 `Missing character` 0 条；将 **PDF 首页 + 任一含图页** 转 PNG 目检，中文无方块、无乱码、图内文字清晰。两条任一不满足即判"否"。
3. **结构齐全**：§1-2 的 9 节全部存在；**第 2 章含"分析"段**、**第 7 章含"结论"与"建议"两小节**；Q3 章明确标注"待 M6 补"，且不含任何编造的 Q3 结果。
4. **页数与体量**：正文 ≥ 6000 字；**字数口径固定为**：仅统计 `sections/*.tex` 中**第 1–7 章**正文的"汉字数 + 英文单词数"，**不含**表格内容、公式、图表题注、参考文献、附录与 LaTeX 注释；统计命令须写进自检（例：去注释后用 Python 正则计数）。PDF ≥ 8 页（含图表）。

### §3-2 专家十条（一条对一条，AGENTS §8）
5. **引用（§8-1）**：参考文献 6–7 篇，英文 ≤2 篇；正文引用与 refs.bib 条目一一对应（无孤儿、无悬空）。
6. **摘要（§8-2）**：数字、专业名词、"针对问题一二三"句式**加粗**；三问结论齐全（Q3 可写"见第 6 章"但不得留空）。
7. **关键词（§8-3）**：6–7 个。
8. **编号与题注（§8-4、R9）**：图 1、表 1 连续编号；**图题、表题一律置于图表下方**；编号只出现一次，图内不重复写编号。
9. **表格做宽（§8-5）**：无细长窄表；单列内容不撑满半页的窄表须改宽或合并。
10. **四段式（§8-7）**：问题一、问题二两章均按"问题描述 → 模型建立 → 算法求解 → 求解结果"组织，四段小标题显式出现。
11. **图文并茂（§8-8）**：**问题一、问题二两章各 ≥2 张图**（Q3 占位章、数据章豁免）；全文图 ≥6、表 ≥4。
12. **图内汉字精简（§8-6，第 2 轮修正）**：只约束**注记性文字**——图内标题、图例文字块、注释文字块，每行 ≤ 12 字、注记总行数 ≤ 6、300 dpi 打印可读、无整句长文；**坐标轴刻度标签与图例条目不计入字数与行数**，但须满足 300 dpi 可读。任一图的注记不满足即判"否"。
13. **排版紧凑（§8-9）**：无整页空白；单页留白 > 页面 1/4 的页数 ≤ 2。
14. **通俗（§8-10）**：每个专业术语首次出现给一句中文解释；抽查 5 个术语。

### §3-3 数字与结论
15. **数字回源**：`数字源对照-M4.csv` 覆盖论文所有定量表述（≥40 条），每条给源文件 + 列/行；抽查 10 条全部对得上。
16. **禁用措辞与定性（R28）**：全文不得出现"分布不健康""基本满足""大致准确"等自我否定/模糊表述；T2/T7/T8 三条偏离必须按 **R28 第 3 项**写成"**刻度不可达命题**"，含"方差比 ≈ R²"的推导。
17. **口径一致**：文中"50 维 / 231 特征 / 226 候选池 / 44 指标 / 186 属性 / 250 样本"与 `状态板.md` 绑定表一致；**不得**用题面的 46/187/40 维/226 样本（差异只在数据说明处显式登记）。

### §3-4 合规
18. **AI 使用声明（草稿级）**：论文有一节 `AI 使用声明`，说明使用了哪些 AI 工具、用于哪些环节；**逐处标注的体例**在本版给出（实际标注 M7 做）。
19. **不虚构**：不得声称"已做过"未做的实验；Q3 章不得出现结果性数字；引用文献须真实可查（DOI 或 URL 齐全）。

### §3-5 格式门
20. **无占位符**：全文无 `【】`、`____`、`TODO`、`待补`。**"待 M6 补"仅允许出现在两处**——第 6 章章标题下的说明、第 7 章结论小节的 Q3 条；除此之外零占位符。
21. **§⑧ 格式门 8 项**：六件套齐全、无 BOM、纯 LF、`python 工具/check_paths.py` 0 错误（贴输出）、脚本可移植、无未决措辞、CSV 规范、CI 绿。
22. **干净检出双跑（R23 + 本轮新增）**：在仓库外干净 clone 中 ① 复跑 `check_paths`，② **完整跑一遍第 1 条的编译序列**，两次结果都贴进自检。
