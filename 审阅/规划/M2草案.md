### §0-1 一个必须先说清的技术前提：变换不影响 Q2

`1.csv` 里**混合了两种量纲**（37 列 log10、33 列原始）。这对 Q2 **不构成障碍**，因为：

> **Spearman 秩相关对任一变量的单调变换不变。** 无论某列是 log10 还是原始量纲，其与另一列的 Spearman 完全相同。

因此 Q2 全程使用 **Spearman**，既与 `2.csv` 的口径一致（C1 已冻结为 Spearman），也天然免疫量纲混合问题。**本方案禁止在 Q2 中使用 Pearson 或任何依赖绝对数值的度量**（如欧氏距离、PCA）。此条写入验收。

### §0-2 两处必须在报告中点明的口径差异

1. **题面与数据说明关于 `2.csv` 的表述相互矛盾**：题面正文写"皮尔逊相关系数"，而附件《数据说明.txt》与实测均为 **Spearman**。
   - **可复算的实测值**（口径：`2.csv` 的 **226 个候选池节点**，经 M1 的 231/231 对齐表映射到 `1.csv` 后逐格比对，缺失取列中位数）：**Spearman 平均 |差| = 2.0×10⁻⁴**；**Pearson 平均 |差| = 8.8×10⁻²**（约 430 倍）。
   - 本方案采 Spearman 正确，但**报告必须点明这一矛盾并说明取舍**——否则评审读到题面的"皮尔逊"会误判我们没按题面做。
   - *（注：早期 T0 分析曾写"0.0005 / 0.0735"，那是在 47 个可直接映射化合物上的子集口径，与本节 226 全池口径不同；以本节数字为准。）*
2. **维度口径两套并存**：Q2 取 `4.csv` 的 **50 维**（Aroma 15 + Flavour 15 + 其他 20），而题面对 Q1 称"约 40 个感官维度"、`3.xlsx` 另有自己的评分卡结构（实为 12 份评分卡 + summary，与题面"10 个 sheet"也不符）。Q2 选 `4.csv` 的 50 维在统计上合理（有 250 条连续标签），但**报告须交代两套口径的对应关系**：

## §3 验收标准（每条可回答"是/否"）

1. **`Q2_top3.csv` 结构**：行数 = **50**（与 `4.csv` 的 50 维一一对应，列名用 `4.csv` 代码）；必需列 `dim, rank1, rank2, rank3, score1..3, s_direct1..3, s_graph1..3`；每行 `rank1..3` 三个化合物名**均非空且互不相同**；全表无 NA。
2. **候选池合规**：`rank1..3` 出现的所有化合物必须属于 `审阅/规划/T0-Q2候选池.csv` 的 **226** 个节点；**不得出现** `Total ester compounds`、`Total hop aroma compounds`、`Total acids`、`Total sulfur compounds`、`Caloric value`。脚本内以集合断言实现，断言失败即退出码非 0。
3. **图必须参与 Top-3 的产生**（题面"构建共表达图 → 结合 `1.csv` 给出 Top-3"的落地）：
   - 直接项 `s_direct(c,d) = |Spearman(1.csv[c], 4.csv[d])|`；
   - 图项 `s_graph(c,d)` = 化合物 c 在共表达图中的邻域 N(c) 内各化合物对维度 d 的 `s_direct` 按边权 `|ρ|` 加权均值；
   - 综合分 `score(c,d) = (1−λ)·s_direct(c,d) + λ·s_graph(c,d)`，**λ 预注册**：λ 与其选择依据（默认 0.5，或交叉验证选优）必须在**跑出结果之前**写入 `Q2_参数.json`；
   - 验收：报告须给出 **λ = 0 与 λ = λ\* 两种设置下、50 维 Top-3 的平均重合度**，以证明图确实改变了选人。
     **重合度度量锁定为 Jaccard**：对每一维 d，`J_d = |T3(λ=0) ∩ T3(λ=λ*)| / |T3(λ=0) ∪ T3(λ=λ*)|`（两者均为 3 元素集合，故等价于 |∩|/|∪|）；报告 **`mean_d J_d`**。**不得**改用 |∩|/3 或其他度量，以保证不同实现可比。
   - 若最终 λ\* = 0（图项权重为零），必须**逐句对照题面**说明"图仅作结构展示"为何仍满足"构建共表达图……给出 Top-3"，且此项须审阅官明确批准；未获批准即判本条不通过。
4. **共表达图可核查**：`Q2_参数.json` 记录边阈值 τ 的定义与取值、节点数、边数；报告中给出 **节点数 = 226**、边数、平均度、连通分量数。若 τ = 0（全连接），须说明为何仍具"共表达图"意义。
5. **稳定性满足题面"或"**：二选一，并在报告中写明选择理由——
   - **甲** bootstrap：`B = 200`（R15 减范围）。**超时压缩下限 `B = 100`**，且压缩**必须经台账裁决并同步修订本条**（角色无权自改验收标准）；重采样单元 = **样本**（250 个 beer），固定种子；输出 `boot_freq1..3`（该化合物进入该维 Top-3 的频率）。
   - **乙** 跨方法 Jaccard：≥2 种独立排序方法（如 `s_direct` 排序、GBM/随机森林重要度排序），输出两两 `jaccard1..3`。
   - 若两者都做，须同时报，且不得互相替代。
6. **50 维 → 预期品类映射表**（新增落盘物，解决"预期品类无来源"）：交 编程/产出/Q2_维度品类映射.csv，50 行 × 列 `dim, R_name, Category, 判定来源行号, 是否可比`。
   - 来源 = `8.xlsx/Sensory names` 的 `Category` 列，经 `R_name` 桥接（实测 **50/50 命中**）。
   - 实测该列取值仅 `Yeast / Others / Hops / Malt / Wild flora`；在 50 个匹配维度中 **Category 为 NaN 的有 3 维**——`aftertaste`、`body`、`overall` → 记"不可比"，**不得**用语义猜测补填。
   - *（注：`Sensory names` 全表 101 行中共 10 行 Category 为 NaN，那 10 行多数不属于 `4.csv` 的 50 维；映射表只按 50 维统计，故是 3 个"不可比"，不是 10 个。）*
7. **化学品类一致性**：化合物侧品类取 `8.xlsx/Sensory thresholds` 的 `origin_paper`，经 **M1 的 231/231 对齐表**桥接到 `1.csv` 字段（**不得**直接用 `chemical_name` 匹配——实测 231 节点仅 **212** 直接命中，会漏 19 个）。
   - 实测 `origin_paper` 取值：`Hops 90 / Yeast 82 / Spices 28 / Malt 24 / Others 22 / Wild flora 6 / Internal standard solution 5 / NaN 4`。注意是 **`Internal standard solution`**（不是 `Internal standard`）；**4 个 NaN 恰为 4 个 `Total*` 聚合行**，已在 226 候选池外。
   - **判定口径（三分类、逐字精确匹配）**：
     - **一致**：化合物 `origin_paper` == 该维 `Category`；
     - **不可比**：化合物 `origin_paper` ∈ {`Spices`, `Internal standard solution`, NaN}，或该维 `Category` 为 NaN；
     - **不一致**：其余。
   - 验收：报告三分类计数，以及 **一致率 = 一致 / (一致 + 不一致)**（分母**不含不可比**，避免被稀释）；单列"不可比"清单及原因。**不得**把不可比并入不一致，也不得默认归入 `Others`。
8. **GBM 全局对照**：把 50 维 × Top-3 合并为化合物集合（去重），与 `GBM importance MDI`（**231 化合物 × 2 列**，注意该 sheet 首行为占位表头，`header=None` 读 232 行、`header=0` 读 231 行）取交集，报告**重合化合物数与占比**。**不得**声称逐维对照——该表无逐维信息。
9. **聚合列单列说明**：单独一节报告 4 个 `*_sum` 与 `Caloric value` 对 50 维的 Spearman 相关性，并声明其不进入 Top-3 评选；若某聚合列与某维的相关性**高于该维实际 Top-1**，须在正文说明该现象及成因（共线性），不得沉默。
10. **确定性**：固定全部随机源（bootstrap 种子、RF 种子、λ 交叉验证的折划分），在仓库根目录重跑 `Q2_共表达.py`，`Q2_top3.csv` 的 md5 **两次一致**；`Q2_参数.json` 内所有影响结果的参数均落盘。
11. **格式门 8 项**（`模板/任务书模板.md` §⑧）：六件套齐全、无 BOM、纯 LF、`python 工具/check_paths.py` 0 错误且输出粘进自检、脚本可移植（环境变量 + 仓库相对默认值）、无未决措辞、CSV 规范、CI 绿。
