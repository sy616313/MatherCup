# 审阅/规划（仅大脑写入，角色不必读）

本目录放**每个里程碑的方案**，一个里程碑一份文件：`Mx草案.md`（M1 即 `M1草案.md`）。

## 里有什么

| 段落 | 谁写 | 内容 |
|---|---|---|
| §0–§5 | 大脑 | 题目摘要、里程碑拆分、依赖、验收标准、时间预算、风险 |
| §6 | 大脑（转录） | 方案校验的结论与问题清单，**原样粘贴，不改写** |
| §7 | 大脑 | 可直接复制的方案校验提示词 |

模板见 `模板/里程碑草案模板.md`。

## 规则

1. **角色不读本目录**。任务书也不点名它——目的是省上下文，不是保密。
2. §6 出现"通过"即冻结；要改就另起 `Mx草案-v2.md`，旧版标"已作废 by v2"。
3. 一次通过不登台账；方案改动导致里程碑范围、验收标准或时间预算变化 → 台账追加 R 条目。
4. 判"返工"最多再校验一轮，两轮不过 → 停机上报人类。
