### 3.4 正文字数统计命令

在仓库根目录执行：

```text
@'
import re, pathlib
files = [f'论文/产出/sections/{i:02d}_' + n for i,n in [(1,'abstract.tex'),(2,'restatement.tex'),(3,'data.tex'),(4,'q1.tex'),(5,'q2.tex'),(6,'q3.tex'),(7,'evaluation.tex')]]
text = '\n'.join(pathlib.Path(f).read_text(encoding='utf-8') for f in files)
text = re.sub(r'(?m)%.*$', '', text)
for env in ['table','figure','equation','align','eqnarray']:
    text = re.sub(r'[\\]begin\{'+env+r'\}.*?[\\]end\{'+env+r'\}', ' ', text, flags=re.S)
text = re.sub(r'\$\$.*?\$\$', ' ', text, flags=re.S)
text = re.sub(r'\\\[.*?\\\]', ' ', text, flags=re.S)
text = re.sub(r'\$[^$]*\$', ' ', text)
text = re.sub(r'\\[a-zA-Z@]+\*?(?:\[[^\]]*\])?(?:\{[^{}]*\})?', ' ', text)
text = re.sub(r'[{}\\]', ' ', text)
cjk = re.findall(r'[\u4e00-\u9fff]', text)
words = re.findall(r"[A-Za-z]+(?:[-'][A-Za-z]+)*", text)
print('CJK', len(cjk), 'EN', len(words), 'TOTAL', len(cjk)+len(words))
'@ | python -
```

输出：

```text
CJK 11067 EN 223 TOTAL 11290
```
