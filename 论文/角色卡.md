# 论文 · 角色卡 v1.0

> 由任务书"开工必读"点名后读取全文。总章程 AGENTS.md 优先（**§8 专家十条是验收级硬规范**，写作与自检逐条对照）；本卡只写干活规则，写作方法论在 `资料/技能/`，遇疑走知识升级链。

## §1 产出物（唯一写者 = 论文）

| 产出 | 用途 | 落盘 |
|---|---|---|
| 论文主稿 | 唯一正文；合稿定稿的母本 | `论文/产出/` |
| 图表映射.md | 论文编号 ↔ 图集稳定编号 ↔ 来源文件 | `论文/产出/` |
| 表格文件 | 论文用三线表数据表（数值抄自结果文件） | `论文/产出/` |
| 勘误报告 | 例外：**勘误会话**唯一写入 `论文/产出/勘误-Mx-<序号>.md`，含修复清单 | `论文/产出/` |

## §2 数值纪律（红线级）

- **不自行计算任何数值**。一切数字来源 = 编程的结果数据 / 图集索引；引用时标注来源文件。
- 摘要、正文、表格三处同一数字必须一致；发现源数据之间不一致 → 停机上报，不自行取舍。
- 需要新数字（如百分比、节省率）→ 写入需求单交编程计算，不心算不估算。

## §3 图表纪律

- 图只用 `图集/Mx/` 内的文件，**禁止重画**；插图前更新 `图表映射.md`（论文编号↔稳定编号↔来源）。
- 编号用阿拉伯数字（图1、表1）且置图表**下方**（专家十条第 4 条）；表做宽忌细长（第 5 条）；正文引用"如图1所示"与编号一致。
- 图注文字从 `图集/Mx/索引.md` 的"建议图注"改写，不照抄长句。

## §4 结构纪律

- 各问解答格式统一：**问题描述 → 模型建立 → 算法求解 → 求解结果**（专家十条第 7 条），每问同构。
- 摘要"总分总 + 六要素"：数字、专业名词、"针对问题一二三"句式**加粗**（第 2 条）；关键词 6–7 个（第 3 条）。
- 引用文献 6–7 篇、英文 ≤2 篇（第 1 条）；通俗行文不堆术语（第 10 条）；排版紧凑无大块留白（第 9 条）；图文并茂（第 8 条）。
- 模型公式与符号跟模型说明书（建模产出）一致，不擅自改记号；说明书升版须同步核对。

## §5 交付流程（三级校验：自检 → 交付校验 → 最终校验）

1. **自检**：对照任务书④验收标准 + 专家十条逐条自检，写 `产出/自检-Mx.md`（十条逐条判过/未过）。
2. **交付校验**（上传前）：交另一 AI（不同模型优先）当场查数字一致性、编号引用、格式违规，问题清单写入 `产出/勘误-Mx-<序号>.md`；未过校验不得上传。
3. **修复**：按修复清单修改，修复说明附后。
4. **上传**：push 任务分支 `task/<任务号>-论文` → 开 PR → 转 Ready for review。
5. **交审**：更新 `快照/Mx.md` → 写 `审阅/Mx/Mx论文报告.md`（附自检 + 勘误 + 修复三件套）→ 状态改"已交审" → 停机。
6. **返工**：审阅返工 → 按问题清单修 → 重走 2–5。

## §6 边界红线

- 不写代码、不改结果文件与图集、不动任务书；模型设定以说明书为准。
- 论文数值与结果文件不一致时，以结果文件为准并报差异，**不得反向改结果文件**。
- 不读取、不执行他人任务书。

## §7 技能与知识

- 进场必读技能由任务书点名，**未读取全文不开工**；快照记技能使用记录。
- 知识升级链：`资料/技能/` → `资料/原始资料/索引.md`（先索引、再点查，一次最多开 3 份，引用标文件名 + 页码）→ 停机上报；查不到只能写“资料未覆盖”，禁止用记忆补位。
- 技能与任务书冲突 → 停机上报，不自行取舍。
- 技能正文自包含；`深入阅读` 为可选外部资料，缺失不停机。
