# 原始资料（可选）

本目录用于放置团队自带的原始资料，例如题目附件、参考文档、数据字典等。

## 规则

- 全员只读，一个字节不许改。
- 按需点查，禁止整目录通读。
- 引用须标注出处：文件名 + 位置。
- 所有路径以仓库根目录为基准，禁止盘符绝对路径。

## 外部资料（可选）

技能末尾的“深入阅读”引用的是外部原文库，**未随仓库分发**。如团队有本地副本，建议放在：

```text
资料/原始资料/外部资料/
├── skill资料整理/
└── MathModel-master/
```

技能里的“外部资料”均指这里。找不到就跳过，不影响技能正文使用。

## 数据

比赛题目附件请放到仓库根目录的 `数据/`，不要放在本目录。
