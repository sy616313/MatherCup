# 原始资料（可选）

本目录用于放置团队自带的原始资料，例如参考文档、算法讲义、往届优秀论文、数据字典等。

## 规则

- 全员只读，一个字节不许改。
- **先看 `精选/`**（33 份、约 28 MB，随仓库分发，赛时以它为准）；精选没覆盖的再按 `索引.md` 点查全库。
- 引用须标注出处：文件名 + 页码/章节；无出处的数字与论断作废。
- 所有路径以仓库根目录为基准，禁止盘符绝对路径。
- **拿不准就查，查不到就停**：查证优先于猜测，没有证据只能上报，不许补位。

## 精选（入库，必读）

`精选/` 是三位队友 clone 就能读的那一份：7 篇 MathorCup 范式的优秀论文 + 26 份算法讲义，约 28 MB。清单、题型对照与使用纪律见 `精选/README.md`。赛题公布后由大脑按题型补 2–3 篇。

## 外部资料（可选，不入库）

技能末尾的“深入阅读”引用的是外部原文库，**未随仓库分发**。团队本地有副本时，用**目录联结**挂到：

```text
资料/原始资料/外部资料/
```

- 挂载方法见 `索引.md` 第四节；`mklink /J` 不复制文件、不占仓库空间。
- 该目录已写入 `.gitignore`，**永不提交**（本地库通常有几个 GB）。
- 具体查什么去哪，见 `索引.md` 第一、二节。
- 没挂载不影响技能正文使用；挂了就必须按索引点查，不许乱翻。

## 数据

比赛题目附件请放到仓库根目录的 `数据/`，不要放在本目录。
