## 三、使用纪律

1. **只读**，不改不删；引用写「文件名 + 页码」，无出处不作数。
2. 一次最多同时开 3 份；先看目录页，再决定读不读正文。
3. 本包没有覆盖到的 → 去 `资料/原始资料/索引.md` 找全库（若已挂载）→ 仍没有 → 写「资料未覆盖」并停机上报，**不许凭印象补位**。
4. 本包随仓库提交，任何人 clone 即得；全库（6 GB）不入库。
5. 赛题公布后，由大脑按题型再补 2–3 篇进 `论文/`，并在本 README 追加行，同时记台账。

## 四、选材说明

按 MathorCup 大数据赛道近四年的出题规律，题型就五类：**时序聚类/分类、回归与时序预测、综合评价、调度优化、图像/深度学习**。每类挑一篇结构最完整的当"范文骨架"，其余看方法；讲义覆盖了这五类背后会用到的算法，缺的部分从全库补。
