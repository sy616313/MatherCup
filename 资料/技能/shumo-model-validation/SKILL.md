# 数学建模 · 模型检验 · 灵敏度分析 · 稳健性

**检验是 70% 队伍缺失的环节（杨祥生原话），做好检验就是直接加分。** 任何模型求解完成后，先按 §1 清单对号入座做强制检验，再做灵敏度与稳健性，最后把结论写进论文（写法见 §5，或触发 shumo-paper-writing）。

## 1. 按方法对号入座的强制检验清单

| 方法 | 必做检验 | 不合格的处置 |
|---|---|---|
| AHP | 一致性 CR=CI/RI<0.1（单序+总排序） | 修正判断矩阵，不得带病使用 |
| 回归 | R²、F 检验、t 检验、残差诊断、（共线性）VIF | 换变量/逐步回归/PLS |
| 拟合 | 拟合优度 R²（不许用眼看！） | 换函数形式 |
| 灰色 GM(1,1) | 级比检验、残差（相对误差）、级比偏差、后验差 C/p | 平移变换/换模型 |
| 时间序列 | 平稳性（ADF）、白噪声残差、AIC 定阶 | 差分/重新定阶 |
| ARIMA 预测 | 残差检验 | 重新定阶 |
| ANOVA/t 检验 | 正态性（Q-Q/S-W）+ 方差齐性（Levene） | 对数变换或非参数（Wilcoxon/K-W） |
| 排队论 | 到达泊松、服务负指数、ρ<1 稳态 | 换模型/仿真 |
| 微分方程 | 数值解步长收敛性、与实际对照 | 修正假设重新建模 |
| PDE 差分 | 稳定性条件（如 λ≤1/2）、网格加密收敛检查 | 缩小步长/隐式格式 |
| 聚类 | 轮廓系数/肘部/Gap，类数业务可解释 | 换算法/换特征 |
| 分类/回归 ML | k 折交叉验证、混淆矩阵/ROC/MAPE、过拟合检查 | 正则化/剪枝/更多数据 |
| 蒙特卡洛 | 收敛性（随次数增加结果稳定） | 加大试验次数 |
| 启发式算法 | 收敛曲线、多次独立运行统计、对比基准 | 调参/换邻域设计 |

## 2. 灵敏度分析标准动作

- **单参数扫描**：关键参数（价格、成本、占比阈值 α、权重）±5%~±10% 扰动，观察目标值/排名变化，画折线图或散点图（2024 C 题 c094：面积占比 0~1 扫描，0.25 处最优）。
- **典型状态表**：取全优/全劣/均值/单因素最优最劣等 11 组典型数据分别求解，列成表对比（c094 做法）。
- **动态调参**：销量/亩产/价格/成本各 +5% 的条件期望对比（c038 做法）。
- **权重扰动**（评价类）：权重 ±10% 后排名是否翻转，证明结论稳定。

## 3. 稳健性/鲁棒性检验（高分动作）

- **鲁棒优化**：不确定因素全取最坏情况求 max min，与原方案对比利润差（c038：差距极小 → 证明模型稳健）。
- **CVaR 风险度量**：max E[利润]−λ·CVaR，置信水平 95%。
- **风险决策矩阵**：蒙特卡洛 1000 组环境状态 × 11 组备选方案 → 益损值矩阵 → 乐观/悲观/最大期望准则选案（c094）。
- **灾害场景法**：查文献定量灾害损失率（寒潮-30%、干旱-9.3%），构造场景方案 + 利润波动指标 φ=(W'−W)/W 选最抗风险方案（c0234）。
- **ML 模型**：对抗样本（GA 生成）、噪声扰动（高斯噪声下准确率降幅）、外部独立数据集泛化验证（2023 MathorCup 优论做法）。

## 4. 结果合理性论证（写进论文的"自证"）

- 与基线对比：先用原始数据算"什么都不做"的基准收益（2024 C 题：2023 年收益 592 万），证明模型方案的提升。
- 极端下界构造：手工构造保守方案的下界，证明模型解优越（c0234 独有技巧）。
- 收敛性验证：进化曲线/蒙特卡洛收敛曲线。
- 解释反直觉结果：结果变差也要解释原因（c0234 问题三收益下降 → 替代性使买方转向低价品、供需压价——敢于解释是亮点）。
- 分布一致性：预测分布 vs 真实分布（KDE/JS 散度）。

## 5. 模型评价章节写法（论文固定结构）

- 优点 4~6 条在前（略多于缺点），从**求解速度、准确度、稳定性**三方面写；
- 缺点实事求是，可写"时间有限、硬件约束"，**不写"知识有限、能力有限"**；
- 改进方向对应缺点逐条给出；推广不玩标新立异的概念。
- 结果检验三问（杨祥生）：模型是否正确合理创新？结果是否正确合理？表述是否清晰、摘要是否精彩？
