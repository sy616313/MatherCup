# 数学建模 · 预测类建模

先按数据条件选方法（选型表），再按该方法的检验清单验证后才能外推。检验细则的完整清单见 shumo-model-validation。

## 1. 预测方法选型表

| 方法 | 数据要求 | 地位 | 关键检验 | 适用 |
|---|---|---|---|---|
| 回归分析（一元/多元/逐步） | 样本 > 3k+1（k=变量数）；自变量低相关；因变量近正态 | **必掌握** | R²、F 检验、t 检验、残差诊断 | 因果解释+预测 |
| 时间序列（AR/MA/ARMA/ARIMA/季节） | ≥2 个周期以上的等间隔序列 | **必掌握** | 平稳性(ADF)、白噪声、AIC 定阶、残差检验 | 销量/价格/流量中短期预测 |
| 插值与拟合 | 离散观测点 | **必掌握** | 拟合优度 R²（不许用眼看！） | 数据补全/加密、短插值 |
| 灰色预测 GM(1,1) | 少至 4~5 个数据 | 小样本首选（不宜优先用于大样本） | **级比检验、残差检验、级比偏差、后验差 C/p** | 贫信息、近指数序列 |
| 微分方程预测 | 有机理 + 参数可估 | 机理类最好方法 | 与实际对照、参数拟合优度 | 人口/传染病/演化过程（→ shumo-mechanism） |
| 马尔科夫预测 | 状态转移数据 | 备用（随机性强时） | 遍历性条件 | 状态随机转移、市场占有率 |
| 神经网络预测 | 大量数据 | 备用+高大上（黑箱，勿优先） | 训练/验证误差对比 | 非线性复杂关系、也可用于检验其他方法（→ shumo-ml-modeling） |
| 小波分析 | 海量无规律数据 | 高大上（小白勿碰） | — | 分离周期成分 |
| Logistic/Compertz 趋势外推 | S 型增长数据 | 常用 | 拟合优度 | 饱和增长、产品普及 |

> ⚠️ 全场最重要的提醒（杨祥生原话）：**预测一定要做检验——70% 的队伍没做过检验！**
> 拟合好不好不能用眼睛判断，必须做拟合优度/残差/后验差等检验，检验通过才能外推。

## 2. 各方法操作要点

**回归分析**
- 流程：假设 y=β₀+Σβᵢxᵢ+ε → 最小二乘估计 → R²/F 检验整体 → 逐系数 t 检验与置信区间 → 残差诊断 → 预测。
- 变量筛选：偏 F 检验、向前选择、向后删除、**逐步回归**。
- 多重共线性 → 偏最小二乘 PLS 或主成分回归（PLS 适合样本数<变量数，成分个数用交叉验证定）。
- ⚠️ 预测不宜超出样本范围外推太远。

**时间序列**
- 分解：趋势 T + 季节 S + 循环 C + 随机 R（加法/乘法模型）。
- 经典方法：移动平均、指数平滑（一/二/三次，α 与初值要选定）、趋势外推四曲线。
- Box-Jenkins 流程：差分平稳化 → ACF/PACF 拖尾截尾形态定阶 → 参数估计 → **残差白噪声检验**（不过就重新定阶）→ 预测；AIC 准则辅助定阶。
- 季节序列：季节指数或季节差分后再 ARIMA；异方差 → ARCH 类。

**灰色 GM(1,1)**
- 四步：①级比检验（必要时平移变换）②一次累加 AGO 建白化方程，LS 估 a,b ③时间响应式还原 ④残差+级比偏差+后验差（方差比 C、小误差概率 p）检验。
- 变体：灰色 Verhulst（S 型饱和）、灾变预测（异常日期）、关联度分析。
- ⚠️ 只宜外推 1~3 步；波动剧烈效果差；宜与回归/时序对比。

**马尔科夫链**
- 建模：状态空间 → 一步转移矩阵 P（行和=1）→ k 步 P⁽ᵏ⁾=Pᵏ → 极限分布 πP=π。
- 吸收链：基本矩阵 N=(I-Q)⁻¹ 得平均吸收时间与概率。
- ⚠️ 状态划分完备互斥、马氏性、遍历性（不可约+非周期）才存在极限分布。

**插值与拟合**
- 插值（过点）：拉格朗日/牛顿/分段线性/三次样条/B 样条/二维 interp2。⚠️ 高次多项式 Runge 振荡 → 分段低次或样条；只宜内插不宜大幅外推。
- 拟合（不过点）：线性最小二乘（正规方程 AᵀAc=Aᵀy）、lsqcurvefit 非线性参数估计。
- 拟合前先画散点图选函数形式。

## 3. 预测题论文的常见组合拳（获奖论文实证）

- 双/多模型对比：ARIMA vs LSTM 按 1-wmape 赋权融合（2023 MathorCup B 赛道主流做法）。
- 聚类分治：先按时序特征聚类，每类套不同预测器，冷启动新对象按类中心距离归类。
- 业务因子修正：大促/节假日/季节因子（品类因子×地区因子+线性插值）乘在常规预测上。
- 检验三件套：平稳性检验、白噪声检验、残差检验 + 1-WMAPE/RMSSE/MAPE/RMSE 指标。
