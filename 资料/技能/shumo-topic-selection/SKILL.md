# 数学建模 · 选题决策

选题的目标是半天内定题并锁定队伍最可能获奖的题位。动作顺序：按题位人设初筛 → 五维打分 → 定题后立刻搭项目骨架。

## 1. 选题三条铁律

1. **开赛半天内定题**，最迟第一天上午结束。每拖一小时都是净损失。
2. **换题代价极大**：
   - 时间上：换题=从头研究，已过去的时间无法回收；
   - 竞争上：评奖**按题分组**进行，坚持原题的对手已领先一天；
   - 结论：除非第一问完全无思路且已坚持一天以上，否则不换。
3. **没有容易的题**：看着容易的题做着做着都是坑（出题人已衡量过工作量）；"第一眼就不想做"的题可能是畏难情绪而非真难。

## 2. 选题打分表（五维，每题 1-5 分）

| 维度 | 问自己的问题 | 权重 |
|---|---|---|
| 数据友好度 | 附件数据看得懂吗？维度/样本量能处理吗？ | 高 |
| 领域陌生度 | 是否需要先花半天学领域知识？（不熟悉的领域谨慎选） | 高 |
| 队伍匹配度 | 题型是否踩中队伍强项（编程强的选大数据/优化，数学强的选机理） | 高 |
| 问题结构清晰度 | 几问？每问能不能一眼看出建模方向？ | 中 |
| 竞争热度 | 选的人多不多？（人少的题获奖率可能更高，但风险大） | 低 |

> 经验：**贴近实际、入口宽的题**适合大多数队伍；需要领域知识的题（如天文导航）留给有相关背景的队。

## 3. 研赛 A-F 题位"人设"（近年高度稳定，选题先对号）

| 题位 | 近年人设 | 适合队伍 |
|---|---|---|
| **A** | 华为/企业命题：通信-信号-芯片算法题。题面长、术语密、门槛高 | 通信/信号/电子背景 |
| **B** | 华为题：介于算法优化与数据回归之间 | 算法+数据双修 |
| **C** | 传统硬优化/工程调度主力位，2021 起也接数据驱动建模 | 运筹/求解器强 |
| **D** | 早年机理/军事题；2023-2024 转向宏观大数据/政策题（数据量最大） | 大数据/统计 |
| **E** | "行业大数据+机器学习"专用位 | 深度学习/统计 |
| **F** | 物理机理仿真或系统级优化压轴位 | 机理/物理背景 |

（本科国赛 CUMCM 类似：A 连续机理、B 离散优化、C 统计数据、D 运筹、E 环境/政策、F 交通/工程。）

## 4. 三条选题经验规则（源自 74 题分布）

1. 队伍有通信/信号/芯片背景 → 优先 A/B（华为题套路固定：实测/仿真数据 + 精度-资源折中算法），风险是题面阅读成本高。
2. 队伍擅长运筹/求解器 → 优先 C 题及 F 的物流排班类（明确目标+规定输出格式的硬优化）。
3. 队伍擅长深度学习/统计 → 优先 D/E（数据量大、任务为"预测+制图+填表"，评分重视结果文件与鲁棒性）；E 题套路成熟但竞争者多。

## 5. 定题后的第一动作

1. 三人各自写一页"我理解的这道题"：目标、约束、数据、每一问的方向。
2. 触发 shumo-problem-reading 画整体技术路线图。
3. 立即建项目文件夹：`data/ code/ figures/ paper/`（编程手 10 分钟搭好骨架，规范见 shumo-coding-solvers）。
