# 数学建模 · 评价决策类建模

评价题先做第一分岔（能不能用一个巧妙指标讲透？），走多指标路线时核心是赋权与检验。评价结果必须配灵敏度分析（→ shumo-model-validation）。

## 1. 第一分岔：单指标 vs 多指标

**A. 单指标/少指标评价**——不需要 AHP/PCA 那些多指标方法，重点是深挖题目原理，构造一个有物理/业务含义的评价量：
- 例（2016 本科 B 题小区开放）：用"平均延误时间"单指标评价，胜过一堆模糊综合评价；也可用"平均速度""拥挤程度函数""道路通行能力"。
- 例：2015 滴滴打车题同理。
- ⚠️ 见到评价题先想：能不能用一个巧妙定义的指标把问题讲透？这是评委眼中的亮点。

**B. 多指标评价**——形式 Y=A₁X₁+A₂X₂+…+AₙXₙ，核心是定系数（权重）：
- 主观赋权：AHP（有判断矩阵）、Delphi、专家打分。
- 客观赋权：熵权法、变异系数法、PCA 贡献率、CRITIC。
- 组合赋权（加分项）：主客观结合，如 AHP×熵权几何/加权平均。
- ⚠️ 多指标评价前必须数据预处理：无量纲化/标准化/归一化；并区分效益型（越大越好）与成本型（越小越好）指标，正向化处理。

## 2. 主要评价方法速查

**层次分析法 AHP**
- 四步：递阶层次结构（目标层-准则层-方案层，每层 ≤9 元素）→ 1~9 标度成对比较矩阵 → 层次单排序（λmax 特征向量归一化）+ **一致性检验 CR=CI/RI<0.1** → 层次总排序+总检验。
- ⚠️ CR≥0.1 必须修正判断矩阵；n≥3 才需检验；主观性强，结果应做敏感性讨论。
- 两种用法：无数据时 AHP 独挑（要两层成对比较矩阵）；有数据时 AHP 只定权重，搭配 TOPSIS/灰色关联/模糊评价。

**TOPSIS**（理想解法）：标准化后找正/负理想解，按贴近度排序；常接在 AHP/熵权后。

**熵权法**：信息熵定客观权重；数据波动大的指标权重大。与灰色关联/RF 并列（获奖论文 2022-B-3 用三法交叉验证影响因素）。

**模糊综合评价**
- 隶属函数（三角/梯形/正态，要说明依据）→ 模糊关系矩阵 → 权重合成 → 最大隶属原则。
- 模糊聚类五步：标准化 → 标定（夹角余弦等）→ 传递闭包 → λ 截矩阵 → 动态聚类图。

**灰色关联分析**：关联系数→关联度，做因素影响排序；与数据变换方式有关，要说明所选方法。

**数据包络分析 DEA**（C²R）：同类单元投入产出的相对有效性（θ=1 有效）；评价的是"相对"效率。

**主成分/因子分析用于评价**：标准化 → 特征值/特征向量 → 累计贡献率 ≥85% 取前 k 个 → 贡献率加权综合得分；解释要结合载荷符号。

## 3. 评价题论文标准动作

1. 指标体系构建（分层次，最好有文献/业务依据）→ 2. 数据标准化（正向化）→ 3. 赋权（主观+客观组合）→ 4. 综合评价模型计算 → 5. 排序/分级结果+合理性分析 → 6. 灵敏度分析（权重扰动后排名是否稳定）。

## 4. 决策准则增量（不确定型决策，课件体系）

当评价/决策对象带有不确定性且无概率分布时，用完整的不确定型决策准则族：乐观(max-max)/悲观(max-min)/Hurwicz 折中系数/等可能(Laplace)/期望值准则；**期望收益=最小后悔值等价定理**；多阶段用决策树（□决策点/○机会点/△末梢，右→左卷回）。有概率分布时用蒙特卡洛生成场景+益损值矩阵（案例见 shumo-award-patterns §1）。
