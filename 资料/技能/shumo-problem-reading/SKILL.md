# 数学建模 · 读题与题型识别

拿到赛题后按本 skill 的动作顺序走：先判题型（分类树），再拆题（四步法），最后落到技术路线图。复合题以主干题型为准、逐问细化。

## 1. 五大题型分类树（第一判断）

```
赛题
├─ ① 优化类（出现最多）：在约束下最大化/最小化某目标
│    信号词：最优、最大收益、最小成本、合理安排、分配、调度、选址、规划
│    → 触发 shumo-optimization；求解器扛不住时 shumo-metaheuristics
├─ ② 预测类：用历史数据/机理推演未来
│    信号词：预测、预报、未来趋势、增长率、估计
│    → 触发 shumo-forecasting
├─ ③ 评价类：给对象打分、排序、定级
│    信号词：评价、评估、重要度、优先级、排名、影响力、方案比较
│    → 触发 shumo-evaluation
├─ ④ 机理/仿真类：物理化学生物过程建模，或随机系统模拟
│    信号词：物理过程、运动、传播、扩散、平衡、稳定性、模拟
│    → 触发 shumo-mechanism
└─ ⑤ 大数据/机器学习类（MathorCup 等大数据赛主流）：给定大样本数据做分类/回归/识别
     信号词：附件给海量数据、用户画像、图像、评分预测、影响因素
     → 触发 shumo-ml-modeling
```

注意：**难题几乎都是复合型**。2024 国赛 C 题（农作物种植）就是"优化为主干，第二问加随机性，第三问加统计相关性"的递进复合题。

## 2. 拆题四步法（读一道题的标准动作）

1. **圈对象与量**：题目里出现了哪些实体（地块/用户/飞行器/产品）、哪些已知量（数据附件）、哪些待求量。列一张"已知→待求"对照表。
2. **数一数问了几问**：一题通常 3~4 问，难度递进。
   - 第 1 问：确定性基线（给数据就能算/建基础模型）
   - 第 2 问：加不确定性/加约束/改目标（在第 1 问模型上修）
   - 第 3 问：最开放（相关性、推广、政策建议），可与现实结合
3. **找约束清单**：把题目里所有"不能/必须/至少/至多/只能"句式全部抄下来编号，这就是未来模型的约束条件来源（获奖论文约束普遍 6~14 条，套路见 shumo-award-patterns）。
4. **画整体技术路线图**：一页纸流程图，问题一→二→三各自用什么模型、彼此什么关系。这张图后期直接进论文"问题分析"章节。

## 3. 命题人视角（判断题目"想考什么"）

- 题目背景都挂靠热点领域：5G、人工智能、大数据分析、绿色环保、气候变化、航天导航……
- 命题人期待"**简单的、实用的模型**"，而不是堆砌复杂方法。（E 题全球变暖原话："希望做出一个简单的、实用的模型，有利于非专业人士理解"。）
- 每道题都有"专业入口宽窄"之分：入口宽的题切入点多，选的人多；入口窄的题（需先学领域知识）选题时要谨慎（见 shumo-topic-selection）。

## 4. 读题时就要想好的三件事

1. **数据够不够**：附件数据维度/样本量 → 决定走统计/机器学习路线还是机理路线。样本少（<10 个点）→ 灰色预测；海量 → 抽样+机器学习；有明确物理规律 → 机理方程。
2. **结果交付形式**：题目是否要求填 result.xlsx / 给出具体数值 / 给方案表格。近年题目普遍要求规定格式结果文件（评分引入机检），编程前就要按格式输出（见 shumo-coding-solvers）。
3. **哪一问能先出结果**：从最有把握的一问开始建立团队信心，但写作顺序仍按 1→2→3。

## 5. AI 辅助读题的合规提醒

AI 可以用于信息搜集、思路开拓，但：模型/公式若来自 AI 且无法确认来源，必须标注并在参考文献列出 AI 工具信息，且"无推导过程、无引用标识的模型公式一律不予认可"——读题阶段的 AI 讨论要落到"自己推导验证过的框架"上。详见 shumo-ai-compliance。
