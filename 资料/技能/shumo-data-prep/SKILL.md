# 数学建模 · 数据预处理与探索性分析（EDA）

适用于一切带数据的赛题（优化题也要先算基线、画图）。按 10 步流水线推进，每一步的处理都要留"处理前后"证据进论文。

## 1. 标准流程（获奖论文通用 10 步流水线）

```
原始数据
→ ① 数据体检（shape、dtypes、describe、缺失率表、重复数）
→ ② 去重、删无关列（ID 类、常数列、方差≈0 列）
→ ③ 缺失值处理（分层策略，见 §2）
→ ④ 异常值处理（业务规则 > 统计规则，见 §2）
→ ⑤ 时间字段规范化（时区/格式/拆解年月日周/构造时长差）
→ ⑥ 类别变量编码（见 §3）
→ ⑦ 连续变量变换（偏度>0.5/1 时 ln(1+x)、box-cox、Johnson SU）
→ ⑧ 标准化/归一化（z-score / min-max / RankGaussian）
→ ⑨ 特征工程 + 特征筛选（见 §4）
→ ⑩ 训练/测试划分（分层抽样；大数据先抽样建模）
```

论文写作提示：把流水线画成流程图放"数据预处理"章节；保留"处理前后"对比图（箱线图/直方图）证明清洗的必要性——评委吃这一套。

## 2. 缺失值与异常值（获奖论文实际做法）

**缺失值分层策略**：
- 缺失率 >50%~90% → 整列删除（但先看业务含义，如"重定向次数缺失 78%"本身可能是信息）。
- 类别变量 → 众数；更好：**分组众数**（按品牌/车型/城市分组填充）。
- 连续变量 → 均值/中位数；更高级（获奖论文最常用）：**KNN 填充**、前后相邻时刻均值、多重插补、按仪器测量下限填充。
- 集中缺失且无补救 → 整行删除（少量时）。

**异常值**：
- 优先业务规则修正而非删除：如二手车价格"109000 万元"= 小数点错位 → 改 10.9 万；二手价 > 新车价（占 0.6%）→ 删。
- 统计规则：3σ、箱线图 IQR、散点图定位。
- ⚠️ 删除/修正都要在论文中给出条数和理由，这是严谨性得分点。

**类别不平衡**（分类任务）：SMOTE、SMOTE+Bagging（SMOTEABAG）、Focal loss（α 调类权重、γ 关注难样本）、Dice loss（分割前景过小）、分层抽样；不要简单过采样后不做交叉验证。

## 3. 类别变量编码速查

| 方法 | 适用场景 | 注意 |
|---|---|---|
| Label / Ordinal 编码 | 树模型、有序类别 | 线性模型慎用（会引入伪序） |
| One-Hot | 线性模型、低基数（<10 类） | 高基数会维度爆炸（有论文 17 特征→536 维） |
| Count / 频数编码 | 高基数（终端品牌、城市） | 配合树模型 |
| Target / 目标编码 | 高基数 + 有监督 | 必须 K 折内编码防泄漏 |
| KMeans 分箱 | 连续变量离散化 | 配合 RankGaussian |

## 4. 特征工程与筛选（拉开论文差距的核心）

- **时间特征**：时长差、淡旺季、季节、昼夜/工作日-周末分组统计。
- **聚合特征**：groupby 后的 mean/max/median/sum/std（按品牌、城市、用户）。
- **自造业务特征**（高分亮点）：如基站论文的"双对数趋势系数、周期差异值 DM、熵特征（样本熵/近似熵）"、二手车论文的"保值率、调价周期两阶段分解"。
- **筛选三路**：
  1. 过滤法：Pearson/Spearman 相关热力图、MIC、卡方检验（离散）、方差阈值；
  2. 包裹/嵌入法：RF/XGB 重要性（Gini + OOB 置换双视角）、Lasso、逐步回归、LOFO、SFS；
  3. 多法融合投票：两种方法各选 Top5 再投票（有优论专门这么做）。
- **防泄漏**：训练集与预测集特征取交集；分布一致性检验（KDE 图、JS 散度）。

## 5. EDA 必做图表清单

直方图/密度图（分布形态）、箱线图（离群+分组差异）、相关热力图（Pearson 数值型 / Spearman 混合型）、缺失率条形图、分组均值条形图、时序曲线（带季节分解）、Q-Q 图（正态性）、词云（文本数据）、散点矩阵。

图表规范与论文呈现方式见 shumo-paper-writing。
