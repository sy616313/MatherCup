# 数学建模 · 机理与微分方程类建模

机理题的流程：确定研究量 → 找基本规律 → 列方程+定解条件 → 求解 → **与实际对照检验并修正**。数值解法与稳定性判断是硬功夫，检验要求见 shumo-model-validation。

## 1. 机理建模三法

1. 按物理/化学规律直接列方程（牛顿定律、能量守恒、化学反应速率…）。
2. **微元分析法**：取小区间/小微元，分析进出量列平衡式。
3. 模拟近似法：对复杂生物/社会现象做合理假设后近似。

## 2. 必会模型库

**人口/种群**
- Malthus 指数增长 dx/dt=rx（短期近似）；**Logistic** dx/dt=rx(1-x/N)（阻滞增长，平衡点 x=N 稳定，参数 r、N 用数据拟合）。
- 种群竞争模型（两种群，平衡点+雅可比特征值判稳）；Volterra 捕食-被捕食（周期解）。

**传染病**：SI/SIS/SIR 族（机理建模+稳定性分析的标准素材）。

**战争模型**：正规战（线性律 dx/dt=-ay）、游击战（抛物律 dy/dt=-cxy）、混合战；用 y-x 平面平衡线判胜负条件。Lanchester 平方律详见教材章节。

**差分方程（离散演化）**
- **蛛网模型**：农产品价格供需波动，|f'(P₀)h'(P₀)| 与 1 比较判断收敛/发散；
- 遗传模型（基因比例转移矩阵 Aⁿ 极限）、养老保险/分期付款（离散资金流）。
- ⚠️ 离散平衡点稳定性看特征根模是否 <1（与连续系统判法不同）。

**稳定性分析**
- 求平衡点（令 f=g=0）→ 雅可比矩阵 → 特征值实部符号判稳。
- 再生资源开发：dx/dt=rx(1-x/N)-Ex，最大可持续产量 E=r/2、x*=N/2；过度开发（临界努力量）导致灭绝——可持续开发类题的模板。
- 优势：不必解出方程就能讨论长期走向。

**常微分方程数值解**
- Euler（O(h)）→ 改进 Euler（预测-校正）→ **RK4**（O(h⁴)，默认选择）。
- Matlab：ode45（非刚首选）、ode15s/ode23s（**刚性方程必须换刚性解法器**）、dsolve（只有特殊方程能符号解，绝大多数必须数值解）。
- 高阶方程降阶为一阶方程组；边值问题用 bvp 系列。

**偏微分方程**
- 差分法：五点格式（椭圆/Poisson）、热传导显式/隐式/Crank-Nicolson；⚠️ 显式格式有稳定性条件（如 λ=a²Δt/Δx²≤1/2）。
- Matlab：一维 pdepe（写方程/初始/边界三函数）；二维 pdetool 图形界面。
- 适用：热传导/扩散、浓度场、振动与波、稳态温度场。

**变分法与最优控制**
- 泛函极值 → Euler 方程；连续时间动态优化（生产-库存、价格调整、最优投资）。
- 最优控制：Hamilton 函数 + 正则方程；控制受限时用最大值原理（bang-bang）。

**信号/定位类（数维杯 A 题实证）**
- 多源信号建模（TOA/TDOA/DFD/AOA/RSSI 各写表达式）→ 最少信号数几何讨论 → **扩展卡尔曼滤波 EKF** 实时估计 → 统计异常检测（滚动均值+标准差阈值）筛偏差信号 → 最小二乘/加权最小二乘融合定位 → 误差分析与轨迹可视化。
- 进阶：牛顿迭代解非线性方程组、克拉美罗界 CRLB 做筛选标准、蒙特卡洛仿真验证。

## 3. 课件增量模型（32 章教材之外）

- **药物房室系统**：快速静注/恒速点滴/口服三种给药的 C(t) 推导；糖尿病 GTT 二房室诊断。
- 放射性鉴年（赝品鉴定）、多级火箭最优级数论证、香烟过滤嘴模型、烟雾扩散。

## 4. 机理+统计混合赛题的六段式套路（2024 数维杯 B 题 7 篇优论实证）

1. 第一问=机理/表达式建模+可行性论证（最少几个、相关矩阵热力图）。
2. 数据预处理前置规范化：缺失插值（线性/Lagrange/测量下限填充）、描述统计表（均值/标准差/峰度/偏度/变异系数 CV）。
3. 统计检验递进链：正态性（Q-Q 图/Shapiro-Wilk）→ 方差齐性（Levene）→ 参数或非参数方法（t 检验/Wilcoxon、ANOVA/Kruskal-Wallis）→ 交互效应（回归交叉项）→ 效应量 Cohen's d。前提不满足先变换（对数）再检验。
4. 中段一问=优化模型（GA/LINGO/fmincon/PSO 求最优配比/最优参数）。
5. 末问=预测模型比武：多模型统一指标（MSE/RMSE/MAPE/R²）择优，Stacking 融合是亮点。
6. 检验固定三件套：分问题误差分析、可视化验证（热力图/收敛曲线/轨迹图）、模型评价。
