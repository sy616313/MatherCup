# 数学建模 · 优化规划类建模

先走选型决策树定模型类别，再按建模五步法落成论文结构。出现频率最高的题型，模板与获奖实证见 shumo-award-patterns。

## 1. 模型选型决策树

```
目标函数和约束都是线性的？
├─ 是 → 决策变量要取整数吗？
│        ├─ 否 → 线性规划 LP（lingo/scipy.linprog/Gurobi）
│        └─ 是 → 整数规划 IP/MILP（0-1规划、分枝定界）
└─ 否（含平方/比值/三角/分段）→ 非线性规划 NLP（fmincon）
     ├─ 目标是多个、可分优先级 → 目标规划（偏差变量+优先级）或加权/ε约束法
     └─ 大规模组合优化（路径/调度/下料）且求解器扛不住 → 启发式（触发 shumo-metaheuristics）
特殊结构：
- 多阶段决策、无后效性 → 动态规划
- 网络上的问题 → 图与网络（最短路/最小树/最大流/匹配/PERT）
- 库存订货 → 存贮论（EOQ 系列）
- 排队服务系统 → 排队论 M/M/1、M/M/s
- 利益冲突双方 → 对策论（博弈）
```

## 2. 各模型核心要点

**线性规划 LP**
- Matlab 标准形 min cᵀx s.t. Ax≤b, Aeq·x=beq, lb≤x≤ub；max/≥ 要变号。
- 决策变量选取是建模关键；非线性项不能硬套（可转化的要显式写出转化）。
- 配套：运输问题、指派问题（匈牙利算法）、对偶与灵敏度分析。
- 典型案例：投资收益与风险（风险约束线性化）。

**整数规划 IP**
- ⚠️ LP 解取整 ≠ 整数最优（有反例）；用分枝定界/割平面。
- 0-1 规划：用 0-1 变量表达"是否/要么…要么…"；隐枚举+过滤条件。
- 大 M 法：连接逻辑变量与连续变量（x ≤ M·y）——获奖论文写约束的标配技巧。

**非线性规划 NLP**
- 一般只保证局部最优 → 多初值试探；凸规划才有全局保证。
- 罚函数法（外点/内点）化约束为无约束；fmincon 的非线性约束返回 (c, ceq)。

**目标规划 / 多目标**
- 正负偏差变量 d⁺/d⁻（不能同时非零）、刚性约束 vs 软约束、优先因子 P₁≫P₂。
- 序贯式算法：按优先级逐级解 LP，上级最优值作为下级约束。
- 多目标也可用加权法、ε-约束法、理想点法；附：DEA（C²R）做单元效率评价。

**动态规划**
- 阶段-状态-决策-指标函数；状态定义必须**无后效性**。
- 逆序递推 fₖ(sₖ)=opt{vₖ+fₖ₊₁}；适用：最短路、资源分配、设备更新、生产库存。

**图与网络**
- 最短路：Dijkstra（⚠️ 不能有负权边）、Floyd（所有点对）。
- 最小生成树 Kruskal/Prim；最大流-最小割（标号法/增广链）；最小费用流；匹配。
- 工程计划：PERT/CPM 关键路线（决定总工期）；中国邮递员（Euler）。

**存贮论（库存）**
- 基本 EOQ：Q*=√(2C_D·D/C_P)；变体：允许缺货、补充时间较长、价格折扣、(s,S) 策略。
- 单周期随机库存（报童模型）：临界分位点法定订货量。

**排队论**
- M/M/1：ρ=λ/μ<1 是稳态前提；Ls=ρ/(1-ρ)；M/M/s、M/M/s/K、损失制 Erlang。
- 系统优化：服务成本+等待损失最小，边际分析定最优服务台数。
- ⚠️ 到达需泊松、服务需负指数；复杂系统改用蒙特卡洛仿真（触发 shumo-metaheuristics）。

**对策论（博弈）**
- 零和矩阵对策：先找鞍点（max-min），无鞍点用混合策略（化为对偶 LP）。
- 双矩阵对策：Nash 均衡（联立方程或 LP）。适用：价格竞争、投标、资源竞争。

**调度与作业计划**
- 流水车间 2 机：Johnson 规则（最小加工时间属第一台排前、属第二台排后）；m 机推广是启发式。Job-shop 是 NP-hard → 启发式+gap 报告。
- 下料问题：枚举切割模式 + 整数规划。
- 生产批量（lot-sizing）：0-1 "是否生产"变量+大 M，瓶颈能力约束别漏。

## 3. 优化题建模五步（直接可当论文模板）

1. **决策变量**：明确下标含义（如 x_ij^t = 第 t 年第 i 地块种 j 作物面积）；复杂题加 0-1 变量。
2. **目标函数**：一个主目标；多目标写加权式并说明权重来源。
3. **约束条件**：分四组编号——资源类/逻辑类/结构类/管理类；**每条约束先写文字动机再写公式**。
4. **模型求解**：说明软件与求解器；大规模时画算法流程图。
5. **结果分析**：最优值+方案表+图；灵敏度分析（触发 shumo-model-validation）。

## 4. 获奖论文的优化题共性（2024 国赛 C 题四篇优论实证）

- 四维决策变量 x_{年,季,地块,作物} + 0-1 逻辑变量 + 大 M/x≤A·z 连接，四篇无一例外。
- 约束 6~14 条逐条编号；超额产量用 λ 因子（0 或 0.5）参数化统一两种情形。
- 小规模确定性 → LINGO/Gurobi 精确解；大规模/非线性 → GA/DEGA/贪心；有论文特意双解法对比。
- 不确定性版：参数→分布（均匀为默认）→蒙特卡洛场景→期望/悲观乐观/CVaR/波动指标选案。
- 完整模板与差异化亮点 → shumo-award-patterns。
