# 数学建模 · 统计与机器学习类建模

大数据赛题的标准解题主线是流水线+按问分解任务。数据预处理细节由 shumo-data-prep 承接；合理性论证与检验由 shumo-model-validation 收尾。

## 1. 大数据赛题的标准解题主线（33 篇优论实证）

```
数据预处理（触发 shumo-data-prep）
→ 探索分析 EDA + 可视化
→ 【任务分解】每问一种任务：
     影响因素分析 → 统计检验 + 特征重要性
     分类/聚类   → 聚类算法 + 定 K + 类别画像
     评分/数值预测 → 多模型横评 + 融合
     图像任务    → 深度学习选型 + 增强 + 迁移学习
→ 模型评估（混淆矩阵/ROC/MAPE/1-WMAPE…）
→ 合理性论证（分布一致性 KDE/JS 散度、灵敏度分析）
```

## 2. 方法库（按任务）

**聚类**
- KMeans（肘部法/轮廓系数/Gap 统计量定 K）、系统聚类（八种类间距离，谱系图定类数）、FCM 模糊 C 均值（改进版可用类内 SSE+类间距离自动定 K）、DBSCAN（密度，抗噪声）、KShape/DTW（时序聚类）、两级/分层聚类（先经验字段一级、再统计特征二级）。
- ⚠️ 变量标准化或马氏距离；类数要结合业务解释。

**降维**：PCA（累计贡献率 ≥85%~90%）、因子分析（方差最大化旋转）、典型相关（两组指标整体相关性，需显著性检验）。

**判别/分类**：距离判别（马氏）、Fisher、Bayes 判别；KNN、SVM、逻辑回归、决策树（CART+CCP 剪枝）、随机森林、朴素贝叶斯。误判率回代检验。

**回归/预测（表格数据）**
- 线性族：多元线性回归+逐步回归（解共线性）、Lasso、岭回归、SVR（2022 优论横评胜出过）。
- 树集成族（2021-22 优论标配）：**XGBoost / LightGBM / CatBoost / RF / GBDT**，贝叶斯优化（HEBO/Optuna）或网格+随机搜索调参。
- 融合族：**Stacking**（基模型 XGB/LGB/CAT，元模型线性回归/GBR，2~3 层）、加权融合（按指标赋权，如 0.2×(1−MAPE)+0.8×Accuracy5）、软/硬投票。

**深度学习**
- 图像分类：VGG16/ResNet/DenseNet/GoogLeNet 预训练+迁移学习（冻结权重+FC 头）；2023 优论已用 ViT。选型靠横评（同数据同协议比准确率/速度）。
- 图像分割：U-Net 系（空洞卷积版/UNet++/MobilenetV2-UNet）、DeepLab-V3（ASPP）；后处理：CRF、腐蚀膨胀形态学、多图平均二值、逐像素投票集成。
- 目标检测：YOLOv5/v8（改进点：注意力 CBAM、CIoU、特征增强模块；配消融实验）。
- 时序：LSTM/GRU/Transformer；小样本时序反而常用 ARIMA/指数平滑/Holt-Winters（→ shumo-forecasting）。
- ⚠️ 黑箱模型不宜作为第一选择；论文中应与统计方法互验。
- 神经网络进阶（RBF/Hopfield/Boltzmann/模糊神经网络/系统辨识）见课件增量：`外部资料/20-课件教程增量知识点.md` §2。

**统计检验（影响因素题的硬通货）**
- 数值 vs 数值：Pearson/Spearman/Kendall（非正态）+ 热力图；MIC（非线性关联）。
- 数值组间差异：t 检验 / ANOVA（前提：正态+方差齐性 Levene）；不满足 → Wilcoxon 符号秩 / Kruskal-Wallis；效应量 Cohen's d 补充。
- 离散 vs 离散：卡方检验 + 效应量化（Phi、Cramér's V、列联系数、Lambda）。
- 权重/重要性多法互证：熵权法 + 灰色关联 + RF 重要性（三法结论一致才稳）。

## 3. 评估指标速查

| 任务 | 指标 |
|---|---|
| 回归 | MAPE、RMSE、MAE、MSE、调整 R²、Accuracy5（5% 误差内比例）、1-WMAPE、RMSSE（时序） |
| 分类 | 准确率、Precision/Recall/F1、混淆矩阵、ROC/AUC、Cohen's Kappa |
| 聚类 | 轮廓系数、肘部 SSE、Gap 统计量、DBI |
| 分割 | IoU、Kappa 系数、Dice |
| 综合 | k 折交叉验证（5/10 折）+ 分层抽样 |

**合理性论证标配**：预测分布 vs 真实分布（KDE 核密度图/JS 散度/柱状图）——"证明预测合理"比"报告分数"更打动评委。

## 4. 2023 优论趋势（区别于 2021-22 的套路）

- **CV 题**：端到端深度学习+多骨干横评+迁移学习；评估"军事化"——鲁棒性（高斯噪声）、对抗样本（GA 生成）、外部独立数据集泛化验证、消融实验、收敛性分析。
- **时序题**："聚类分治 + 经典模型为基（ARIMA/指数平滑）+ 业务因子修正（促销力度值、品类×地区因子+阶段线性插值）+ 轻量融合（按指标赋权）"。贝叶斯调参与 Stacking 并非必需；冷启动用相似序列迁移（Spearman/余弦相似度）。
- **简约建模也是立场**：有优论明确以"简易性、实用性、可解释性"为由弃用深度学习，并给出平稳性/白噪声/残差完整检验——**方法与题目的匹配度 > 模型名字的新潮**。
