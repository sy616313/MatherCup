# 数学建模 · 现代智能优化算法

启发式是精确求解器的补充而不是替代：先确认精确算法为什么不行，再上启发式，并按论文规范报告。

## 1. 什么时候用（定位）

- 对象：**NP-hard 组合优化**（TSP、车辆路径、车间调度、下料、背包、网络布局、侦察路径规划）与不可导/多峰复杂函数。
- 本质：**启发式**——只求满意解不保证全局最优；论文必须报告与已知最优或其它算法的对比。
- ⚠️ 白箱优先原则：能用 LP/NLP 精确求解器解的不要上启发式；用了要说明为什么（规模/非线性/离散结构），并做收敛性验证。论文中论证"为什么用启发式"可用 P/NP 语言（见 `外部资料/20-课件教程增量知识点.md` §1）。
- ⚠️ 黑箱模型（神经网络）与灰箱同样"不宜优先"，可作为检验手段或最后手段。

## 2. 五大算法要点

**遗传算法 GA**
- 流程：编码（实数/二进制/排列）→ 初始化种群 → 适应度 → 选择（轮盘赌/锦标赛）→ 交叉（概率 pc）→ 变异（小概率 pm）→ 精英保留 → 迭代。
- 典型参数（2024 C 题 c0234 优论）：种群 50、迭代 500 代、交叉 0.1、变异 0.01。
- 改进点（优论亮点）：反向学习初始化、差分进化变异 DE（c038 的 DEGA）、早熟判断（最优个体占比>10% 注入新个体）、三次样条拟合设计适应度。

**模拟退火 SA**
- Metropolis 准则：按 min(1, exp(-ΔE/T)) 概率接受劣解 → 缓慢降温。
- 关键：初温、降温调度、邻域设计；应用例：炼油厂原油库存调度。

**粒子群 PSO**
- 速度-位置更新，个体最优+群体最优牵引；惯性权重线性递减是常见改进。
- 应用例：物流配送路径。

**蚁群算法 / 禁忌搜索**
- 蚁群：信息素正反馈+挥发系数防早熟，解 TSP；禁忌搜索：禁忌表+特赦准则。

**蒙特卡洛法**
- 思想：随机撒点/随机模拟 → 统计平均；"几乎是比赛必用的方法"。
- 用途：定积分估计、概率风险模拟（2024 C 题：1000 组随机状态+益损值矩阵+决策准则）、排队系统仿真、检验模型正确性。
- ⚠️ 精度依赖试验次数；要报告收敛情况。
- 方差缩减四技巧：重要抽样、俄国轮盘赌与分裂、分层抽样、系统抽样；误差 ε=O(N^-1/2)。
- 排队系统 MC 仿真完整代码模板（理发店案例：经验分布表→随机数区间映射→离散事件推进）见 `外部资料/20-课件教程增量知识点.md` §2。

## 3. GA/SA 工程技巧（应用论文增量）

- 双螺旋染色体编码 + 优中差三层种群 + 交叉变异概率随种群结构动态变化（防早熟）。
- SA+逻辑编程+LP 校验混合框架解大规模混合 MILP 调度（炼油厂原油调度案例）。

## 4. 使用启发式算法的论文规范（评委视角）

1. 说明为什么精确算法不行（规模/结构）。
2. 编码设计与约束处理方式（罚函数法最常见——把违反量乘大系数并入适应度）。
3. 参数表（种群/迭代/pc/pm/初温…）+ 参数敏感性或调参依据。
4. **多次独立运行取统计量**（最优/均值/方差），报告收敛曲线。
5. 与其它算法或贪心/求解器对比（c063 优论特意对比 Gurobi vs 贪心并分析权衡）。
6. 结果合理性论证（如 c0234 构造"极端下界方案"证明解的优越性）。

## 5. 风险度量升级包（优化+不确定性的高分组合）

- CVaR（条件风险价值）：损失=基准收益−不确定收益，置信水平 95%，目标 max E[利润]−λ·CVaR（2024 C 题 c038 用此拿到高级感）。
- 鲁棒优化：max min（最坏情况最优）；场景法：蒙特卡洛生成场景+期望最大化；决策准则族：乐观/悲观/最大期望/利润波动指标 φ=(W'−W)/W。
- 完整模板见 shumo-award-patterns；检验与稳健性见 shumo-model-validation。
