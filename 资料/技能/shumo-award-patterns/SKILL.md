# 数学建模 · 获奖论文套路库

把获奖论文的实证经验按三类赛题对号入座：先判用户做的是哪类题，取对应模板的逐问结构；需要具体某篇论文全文时按 §5 指引检索。

## 0. 三类赛题总对照

| | 优化类（国赛 C 题型） | 大数据类（MathorCup） | 机理+统计类（数维杯） |
|---|---|---|---|
| 主线 | 决策变量+目标+约束的递进建模 | 预处理→特征→模型→评估流水线 | 机理建模→统计检验→优化→预测 |
| 第一问 | 确定性基线模型 | 数据预处理+基础模型 | 机理表达+可行性论证 |
| 第二问 | 加不确定性（随机优化） | 多维评估/多模型对比 | 统计检验+效应量化 |
| 第三问 | 加相关性/推广 | 输出结果/业务建议 | 预测模型比武+择优 |
| 高分手段 | 灵敏度+CVaR/鲁棒 | 特征工程+融合+合理性论证 | 检验完备+双模型对比 |
| 代表论文 | 2024 国赛 C 题 4 篇 | MathorCup 2020-2023 33 篇 | 数维杯 2024 11 篇 |

## 1. 优化类标准模板（2024 国赛 C 题四篇实证）

**建模递进三问式**：
- Q1（确定性基线）：四维决策变量 x_{年,季,地块,作物} + 0-1 变量（大 M 法连接）→ 目标 max 利润（收入用 min(产量,需求) 截断，超额用 λ 因子参数化 0/半价两种情形）→ 约束 6~14 条分四组编号（资源/逻辑/结构/管理）→ 精确求解器出基准。**必做**：先用历史数据算基线收益（592 万）+成本-利润可视化。
- Q2（不确定性）：文字区间→分布（均匀默认/正态需说理）→蒙特卡洛 100~1000 场景 → 决策准则选案（期望最大 / 乐观悲观 / CVaR / 波动指标 φ）→ 输出抗风险方案并**解释与 Q1 差异**。
- Q3（相关性/耦合）：证据链（S-W 检验→Spearman 热力图；或文献佐证；或自定系数）→ 转化为模型元素（替代=需求转移/负向约束；互补=软约束 产量×1.01、成本×0.99；量价成本相关=增长率耦合）→ 重解 → 与 Q2 对比并解释升降原因。

**四篇的差异化亮点（可借鉴的具体招）**：
- c038：自研 DEGA（差分进化改进 GA+反向学习）+ CVaR + 鲁棒/动态调参双重检验（最完整）；
- c063：Gurobi 与贪心双解法对比+权衡分析；约束集合化写法最规范；p/q 管理参数网格寻优；
- c094：益损值矩阵+乐观/悲观/期望三准则；LINGO 全局求解器；灵敏度散点扫描；
- c0234：集合论记号压缩约束、sgn 函数处理种植逻辑、λ 滞销利润因子参数化、灾害因子（文献定量化寒潮/干旱损失率）+ 极端下界合理性论证。

**约束清单素材库**（此类题通用的 12 条约束写法）：面积上限、最小面积占比、地块类型-作物白名单、禁重茬（三种相邻情形乘积=0）、三年一次豆类（Σ≥面积）、分散度（每作物地块数上限 m_j=5）、产量-需求匹配、半价情形、单地块单作物数上限、食药用特殊限制、逻辑连接 x≤A·z、大 M 法。

## 2. 大数据类标准模板（MathorCup 33 篇实证）

**预处理流水线**（触发 shumo-data-prep）：体检→去重→缺失（KNN/分组众数/分层策略）→异常（业务规则修正）→编码五法→变换（ln/box-cox/Johnson SU）→标准化→特征工程→筛选（过滤+嵌入+多法投票）→防泄漏（交集+KDE 一致性）。

**按任务选型**（方法细节触发 shumo-ml-modeling）：
- 影响因素分析：统计检验链（正态→方差齐→t/ANOVA 或 Wilcoxon/K-W→效应量）+ 三法互证重要性（熵权/灰色关联/RF）。
- 分类/聚类：KMeans+三法定 K、FCM 自动定 K、DBSCAN、两级聚类；类别画像逐类描述；不平衡用 SMOTEABAG/Focal loss。
- 数值预测：树集成横评（XGB/LGB/CAT/RF）→ 贝叶斯调参（Optuna/HEBO）→ Stacking/加权融合 → Accuracy5/MAPE/RMSE 多指标。
- 时序预测（2023 趋势）：聚类分治 → 每类 ARIMA/指数平滑为基 → 业务因子修正（促销力度值、品类×地区因子+插值）→ 轻量融合 → 冷启动用相似序列迁移。
- 图像（2023 趋势）：增广平衡小样本 → 多骨干横评（VGG/ResNet/DenseNet/ViT/YOLO）→ 迁移学习微调 → 评估"军事化"（噪声鲁棒、对抗样本、外部数据集泛化、消融实验）。
- 运筹混合（2022-A）：MILP+贪心双轨、多批次压单阈值寻优、C++ 程序合法性检验。

**摘要句式模板**："针对问题一，本文首先…（数据动作），随后构建了…模型，结合 N 个约束/特征，采用…算法求解，得出了…（具体数值），并通过…（图表）直观展示了…。"

## 3. 机理+统计类标准模板（数维杯 2024 实证）

六段式：机理表达与可行性论证 → 前置规范化预处理（描述统计表+插值）→ 统计检验递进链（前提检验决定方法选择，写了就是加分项）→ 中段优化模型（GA/LINGO/fmincon/PSO）→ 末问预测模型比武（统一指标择优+Stacking）→ 检验三件套（分问误差分析/可视化验证/模型评价，65 页的 B2024042526531 含"模型的改进"专章回改前文模型——评审最喜欢的自我修正结构）。

定位类专题（A 题）：信号建模（TOA/TDOA/DFD/AOA/RSSI）→ 最少信号数几何讨论 → EKF 实时估计 → 滚动均值+标准差阈值筛偏差信号 → 加权最小二乘融合 → 误差分析+轨迹可视化；进阶：CRLB 筛选标准、蒙特卡洛验证。

## 4. 所有获奖论文的共性（跨类别）

1. **摘要里必须有具体数值结果**（收益 4530 万、Kappa 0.9587、目标值 0.612838、阈值 2.485GB）；
2. 每问一段独立成章，问题间有"在第一问基础上"的递进衔接；
3. 检验/灵敏度专节；模型优缺点都写；
4. 图表丰富且每图有说明（10~25 张/篇）；
5. 附录完整可复现代码；结果文件对齐题目要求的交付格式；
6. 方法与题目匹配 > 模型名字新潮（2023 有优论明确弃用深度学习并拿优）。
